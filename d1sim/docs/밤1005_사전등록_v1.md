**쌍마다** (같은 블록 · 같은 자원, A = d100, B = d50):
- **같은 일 조건**: 일 비 n_B / n_A ≥ 0.95 → "같은 일", 아니면 "같은 일 아님 — 비교 기술만"
- 차이 Δ = A − B (양수 = B 가 열 부담 낮음): Δ최고 SKIN (℃) · Δt38 · Δt40 · Δt42 (s) · Δ조임 시간 (s) · 처리율 비 (B / A) · 일 비 · **B 가 같은 일에 닿은 시각** = B 의 누적 추론이 n_A 에 닿은 첫 10 s 칸의 끝 (s, 못 닿으면 "못 닿음") 과 그 시각 − 300 s
- **선별 기준 (볼 만한 차이 — 정확도·유의성·우월성 기준 아님)**: Δ최고 SKIN **1.0 ℃** · Δt38 · Δt40 · Δ조임 시간 **60 s** (Δt42 는 기술만)
- 지표마다 부호: Δ ≥ 기준 → **+** (B 낮음) · Δ ≤ −기준 → **−** (B 높음) · 그 밖 → **0**

**자원마다** (2쌍 — 선별 지표 4개의 부호로, 위에서부터 먼저 맞는 것 하나):
1. **"같은 일 아님"**: 한 쌍이라도 같은 일 조건 실패
2. **"차이 없음 (2쌍)"**: 두 쌍 모두 모든 지표 0
3. **"B 낮음 (2쌍)"**: 두 쌍 모두 + 인 지표가 하나 이상 있고, 어느 쌍에도 − 가 없다
4. **"B 높음 (2쌍)"**: 두 쌍 모두 − 인 지표가 하나 이상 있고, 어느 쌍에도 + 가 없다
5. **"맞바꿈 (2쌍)"**: 두 쌍 모두 + 인 지표와 두 쌍 모두 − 인 지표가 각각 하나 이상 있고, 두 쌍 사이에 + 와 − 가 뒤집힌 지표가 없다
6. **"엇갈림"**: 그 밖 (한 쌍만 · 쌍끼리 방향 반대 · 한 쌍에만 − 등)

**결론 문장 (지금 고정 — 숫자만 채운다; 조건 괄호는 전부 공통)**:
- B 낮음 → "S26 [NPU/GPU] 에서 같은 일 (추론 ○ 건) 을 d50 으로 나눠 하자, d100 으로 몰아서 할 때보다 [두 쌍 모두 + 인 지표: 최고 SKIN ○ ℃ 낮음 · 38/40 ℃ 초과 ○ s 감소 · 조임 시간 ○ s 감소] 였다 (2쌍 같은 방향). 대신 같은 일에 닿는 데 ○ s 더 걸렸고 처리율은 ○ vs ○ 추론/s 였다 (B 일 비 ○)."
- B 높음 → "S26 [NPU/GPU] 에서 같은 일을 d50 으로 나눠 하자 [두 쌍 모두 − 인 지표] 가 오히려 ○ 늘었다 (2쌍 같은 방향, B 일 비 ○) — 이 조건에서 나눠 하기는 열 부담을 줄이지 않았다."
- 맞바꿈 → "S26 [NPU/GPU] 에서 같은 일을 d50 으로 나누자 [+ 지표] 는 ○ 줄고 [− 지표] 는 ○ 늘었다 (2쌍 같은 방향, B 일 비 ○) — 세기는 열 부담의 모양을 바꿨다 (줄였다고 쓰지 않는다)."
- 차이 없음 → "같은 일을 d50 으로 나눠도 열 부담 지표가 선별 기준 안이었다 (2쌍) — 이 조건에서 세기 차이로는 열 부담이 바뀌지 않았다."
- 엇갈림 → "2쌍이 엇갈렸다 — 이 자료로 세기의 효과를 말하지 않는다."
- 같은 일 아님 → "d50 이 정한 시간 안에 같은 일을 못 했다 (일 비 ○) — 비교 기술만."
