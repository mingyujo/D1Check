## 4. G50P2 — GPU d50 탐침 2런째

- **v1 판정 그대로** (`밤1004_사전등록_v1.md` §3 — `night1004_judge.py g50p`): `ref_d50` · 가열 1-1 진입 · 240~300 s 배율 · 전제 (≥ 1.5) · 해제 (칸 k + 뒤 3칸 ≤ ×1.10, k ≤ 44) · 분류 · H-ap-히스 (해제 칸 AP_k ≥ 40.0 → 기각)
- **새 항목** (`day1005_judge.py g50p2`):
  - **d50 재조임** = 해제 칸 k 뒤 첫 칸 k′ (k < k′ ≤ 44) 로서 칸 k′ 와 뒤 3칸이 모두 ≥ `ref_d50` × **1.10** → 10k′ s · SKIN_k′ · AP_k′. 해제 없음 → "해제 없음" · k′ 없음 → "탐침 480 s 안 재조임 없음"
  - **온도 차** Δ = SKIN_k′ − 같은 런 d100 1-1 진입 SKIN. **Δ ≥ +0.5 → "높은 온도"** · |Δ| < 0.5 → "같은 온도대" · Δ ≤ −0.5 → "낮은 온도" · d100 진입 없음 → "비교 불가"
  - **결론 문장**:
    - 재조임 · 높은 온도 → "뜨거운 GPU 를 d50 으로 내리면 ○ s 안 풀리고, d50 평형에서 ○ s 뒤 d100 진입보다 SKIN Δ ℃ 높은 곳에서 다시 조여졌다 (2런째) — 문턱이 부하에 따라 다르다는 관측과 맞고, AP 히스테리시스 + SKIN 재진입과는 못 가른다"
    - 재조임 · 같은 온도대 → "d50 재조임 온도가 d100 진입과 같은 온도대 — '부하에 따라 다른 문턱' 의 근거는 이 런에 없다"
    - 재조임 없음 → "480 s 안 재조임 없음 — 10/4 의 d50 재조임은 재현되지 않았다"
  - 10/4 G50P 를 같은 규칙으로 계산한 값 (개발 — 이 규칙을 정할 때 본 자료, 기술): 재조임 320 s · SKIN 38.0 · d100 진입 SKIN 37.3 → Δ +0.7 "높은 온도" [P `day1005_judge.py` 를 `out_1004\G50P.json` 에 실행]
  - v2 대응 (§5 표 [D]): R50-fast → "v2 GPU gate 기각 → v1 AP 적분형 쪽" · R50-none → "v2 GPU gate 와 같은 방향"
  - 기술: 탐침 끝 60 s (칸 42~47) 배율 중앙 · 재조임 칸 앞 60 s 의 SKIN·AP 궤적
- **반대 해석**: ① d50 이 평형에서 계속 데워 SKIN 이 오르다 넘은 것 — "높은 온도" 가 문턱 차인지 온도 상승의 끝인지 못 가른다 → 재조임 칸 앞 SKIN 궤적을 적는다 ② 시작 상태 (첫 칸이 되면 "하한 미달 시작") ③ 1런 · CompiledModel 엔진 (0928 M3 은 Interpreter — 참고만) ④ ×1.2 와 ×1.05 가 번갈아 나오는 구간 (10/4 170~310 s) — k′ + 뒤 3칸 규칙이 거른다
