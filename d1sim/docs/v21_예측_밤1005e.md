## 4. 읽는 법 · 한계

- 모형이 "같은 일 아님" 을 예측하는 칸은 없다 (B 일 비 NPU 1.13~1.16 · GPU 1.36~1.59 ≥ 0.95). 칸 길이는 사전 등록 그대로 두었다.
- **열 파라미터 = MobileNet 그대로** (이전 가정). 그래서 이 밤의 cmp 는 "모형 + 모델 바꿈 가정" 을 함께 시험한다. 틀린 몫을 둘로 가를 수 없다.
- "v2.1 미완" 형태의 예측이다. v2.1 이 v2 보다 많이 맞아도 "검증됨" 이 아니다 (1밤 · 자원당 2쌍).
- 처리율은 R0 / ratio 로만 낸다. d50 가동 창 첫 추론 지연과 NPU 전환 잔재는 없다. EffNet R0 는 정의가 MobileNet 과 다르다 (§1).
- BAT₀ 는 z = 0 이다. cmp 는 시작 SKIN 열만 고른다.
- N1 결과는 보지 않았다 (사전 등록 §8). 이 예측은 N1 전에 고정된 모형을 구동 파일만 새로 해서 돌린 것이다. 그래서 **N2 는 세 모형의 다른 모델 홀드아웃**이다 (사전 등록 §5).
- 이 밤 자료로 형태·파라미터를 고르면 다음 자료에서 다시 확인한다 (사전 등록 §9).
