## 6. 반대 해석 먼저 (ground-truth)

- "②·③ 실패는 형태가 아니라 피팅(식별)이 나쁜 것" → 부분 지지: T_on 은 d100 피팅 런에서 식별이 약하다 (d100 에선 AP 가 문턱을 빠르게 지나가 T_on 40.5~42 가 거의 같은 목적함수). 그러나 r3 에서 **측정 AP 를 그대로 넣은 B 단계**(제어기만)는 10 s 배율 RMS 1~7 % 로 맞는데 닫힌 고리에서 −90~−120 s 가 나므로, 틀린 것은 **전력 → AP 하위모형**(처음 300 s 에 ~1 ℃ 과대) 이다. 식별 문제가 아니라 AP 동역학 형태 문제 [E]
- "⑤ GPU 피해자 ×1.4 는 K 가 작아서" → K 를 키우면 ①의 d100 진입·평탄 기울기가 깨진다 (같은 K 로 식은 출발 60~90 s 진입과 뜨거운 출발 10 s 안 ×2 를 둘 다 못 낸다) — **적분 제어기 하나로는 두 관측이 양립 못 함** → 깊이가 온도의 함수(정적 성분)+지연이거나 상태가 두 개 [E]
- "⑥ 통과는 T_off 를 M1 로 맞춰서" → **아니다** — 실측 AP 를 넣은 T_off 피팅은 "허용 구간 없음" 이었고 placeholder(T_set−2 = 39.2) 로 닫힌 고리를 돌렸을 때 30 s 가 나왔다. 1런 · 경계값
- "열 모형 피팅에 N1300 을 넣어 NPU 가 유리" → NPU 자체 지표(계단 시각)가 가장 많이 틀렸다. 유리하지 않다
- "⑦ CPU +38 % 는 시작 SKIN 30.3 가정" → 30.3 은 9/14 중앙값 [D]. CPU 피팅 런(31.6 시작)에서 60 s 칸 배율은 실측 +23 % [D 0928 1-1] — 모형은 K·u_max 로 60 s 안에 포화해 과대. CPU 는 AP 가 5 s 에 42 를 넘는데 지연은 10~20 s 부터 오르므로 d_on 10 s 는 맞지만 깊이 적분이 너무 빠르다
