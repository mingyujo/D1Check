## 2. 계측 정의 (지금 고정)

1. **창** = 열 판정과 같은 창 (구간 0 시작 ~ 마지막 구간 끝 — 세기 A/B · 에너지 C 는 900 s). 창 계산은 판정기 (`night1005_judge.py` · `night1005e_judge.py` · V3 는 `v3_judge.py`) 함수를 **import** 한다.
2. **시계 맞춤** — d1check 표본 (`mono_ns`) 을 구간 경계에 맞출 때 열 판정기가 같은 logger 의 HAL 표본에 쓰는 변환을 그대로 쓴다. **맞춤 검사** (런마다): 첫 가동 구간 (세기 A/B · 에너지 C 는 구간 0, V3 는 첫 duty ≥ 10 구간) 시작 뒤 30 s 평균 방전 전류 > 시작 전 30 s 평균 × 1.3 이 아니면 그 런은 "시계 맞춤 실패" 로 멈추고 보고한다 (selftest 에 넣는다).
3. **표본** — 창 안 d1check 표본 중 `current_valid` · `charge_valid` 가 True 인 것만 쓴다. 시작 · 끝 값 = 창 안 첫 · 마지막 유효 표본.
4. **E_cc (주 지표, J)** = 잔량계가 줄어든 표본마다 Σ (줄어든 µAh × 3.6×10⁻³ C/µAh) × (그 표본의 `voltage_mV`/1000).
5. **E_int (보조 지표, J)** = Σ 사다리꼴 [(−I_i)·V_i + (−I_{i+1})·V_{i+1}]/2 · Δt — I = `current_raw` × 10⁻⁶ A (µA · 방전 음수 [D §10.1]) · V = `voltage_mV` × 10⁻³.
6. **R_run** = Q_int / ΔQ_cc — **창 안에서** 계산 (`s26_energy.py` 의 `total_ratio` 는 런 전체라 다르다) · Q_int = −∫I dt / 3600 (µAh, > 0) · ΔQ_cc = 시작 − 끝 (µAh, > 0).
7. **한 눈금** q = 4,275 µAh [P] → q_J = 15.39 C × (창 안 유효 전압 표본의 중앙값). 쌍 기준 q̄_J = 두 런 q_J 평균.
8. **작업량** n = 창 안 완료 추론 (판정 JSON 구간 n 의 합) · **r** = n_B / n_A (V3 는 n_ours / n_기준선).
9. **런 제외** (결과 전 고정 · 하나라도 걸리면 그 런과 그 런이 든 쌍을 "제외 (사유)" 로 표에 남기고 판정에서 뺀다): 창 안 `plugged` ≠ 0 표본 · 무효 표본 > 1 % · 표본 간격 > 10 s · 잔량계 증가 · 4,275 µAh 배수가 아닌 잔량계 변화 · ① FAIL (§3) · 창 마지막 60 s 의 명령 duty > 1 (끝이 쉼이 아님) · 시계 맞춤 실패.
10. **작업량 보정 (기술 · 에너지 C 강건성)** — ê_B = [E_int(B 의 work 구간) − P_tail × T_work] / n_work (P_tail = B 의 tail 구간 마지막 min(120 s, 길이) 의 E_int 평균 전력) · **ΔE_adj = ΔE + (n_B − n_A) × ê_B**.

## 3. 계측 판정

- **① 단위** (§11-4 그대로): 런별 R_run ∈ [0.5, 2] · 방전 표본 음수 → PASS (FAIL 런은 §2-9 제외).
- **② 내부 일관성** (§11-4 그대로): 세션마다 R_sum = ΣQ_int / ΣΔQ_cc · |R_sum − 1| ≤ 3·σ_R/√N (σ_R = 런별 R 의 모집단 sd · N = 제외 뒤 런 수). **N < 8 이면 σ_R 대신 §10.2 의 0.080 을 쓴다.** → PASS / FAIL. ② 결과는 결론 문장에 늘 한 줄로 붙인다.
- **②′ 팔 사이 일관성** (새로 — 부하 모양에 따라 두 읽기가 다르게 치우치는지): 에너지 C 의 쌍마다 d_R = R(A) − R(B). **|평균 d_R| > max(0.03, 3·SE(d_R))** (SE = 표본 sd/√n) 이거나, 방향 판정이 나왔는데 E_int 기준 평균 차이의 부호가 E_cc 기준과 다르면 → **"계기 불일치 — 기술만"** (§4 의 모든 판정에 우선).
- 절대 정확도: **미인증**. 모든 J 문장에 "연료게이지 잔량계 기준 · 절대 정확도 미인증".

## 4. 판정 — 에너지 C (Q1)

- **쌍 차이** ΔE_p = E_cc(A) − E_cc(B) (J). **양수 = B 가 에너지가 적다** (열 판정 Δ = A − B 와 같은 부호).
- **판정에 넣는 쌍** = 에너지 C 의 같은 블록 쌍 (EffNet NPU 만) 중 §2-9 제외 · r ∉ [0.96, 1.04] ("작업량 차 — 기술만") 을 뺀 것. n = 그 수.
- **SE** = max(표본 sd(ΔE_p), 0.58·q̄_J) / √n (0.58·q̄_J = 쌍 차이의 양자화 sd [E] — 바닥).
- **규칙** (위에서부터, ②′ 가 먼저):
  1. n < 4 → **"쌍 부족 — 기술만"**
  2. |Δ̄| > 3·SE · |Δ̄| > q̄_J → Δ̄ > 0 이면 **"B 낮음"**, Δ̄ < 0 이면 **"B 높음"** (동등 범위 여부를 덧붙임)
  3. |Δ̄| + 3·SE ≤ 2·q̄_J → **"동등 범위 안 (±2 눈금)"**
  4. 그 밖 → **"구분 안 됨"**
- 기술 (판정 아님): 쌍별 부호 · ΔE_p/E_cc(A) (%) · ΔE_adj · E_int 기준 같은 계산 · 창 E / n (mJ/추론, idle 포함).
- "3σ" 라고 쓰지 않는다 (n 이 작아 t 분포 꼬리가 두껍다 — 3·SE 는 등록한 문턱일 뿐).
- **판정 시점** = 에너지 C 목표 8쌍 (§6) 이 끝났을 때, 또는 폰 마감 (10/10 06:00) — 그때까지 끝난 쌍으로 **한 번만** 판정한다. 중간에 판정하지 않는다 (C1 만 끝난 뒤 숫자를 보더라도 C2 를 멈추거나 늘리지 않는다).

## 7. 반대 해석 (결과 전 목록)

1. **잔량계가 쿨롱 계수가 아니라 SOC 추정에서 나온 값일 수 있다** — 한 눈금 4,275 µAh ≈ 배터리 용량 (~4,300 mAh [D 9/13 기기 확인]) 의 0.1 % · ~30.7 s 격자로만 바뀐다 [P 10/3] → 부하 · 온도에 따른 추정 보정이 섞이고, 그 보정이 d100 · d50 에서 다르면 쌍 안에서 상쇄되지 않는다 (`미확인` — ②′ 로 일부만 본다).
2. 잔량계 갱신이 1~4 눈금씩 몰려 온다 → 창 끝이 쉼이어도 경계 오차는 ±1 눈금보다 클 수 있다.
3. 전류 적분은 1 Hz 표본 — d50 의 5 s 가동 / 5 s 쉼을 1 Hz 로 본다 (런당 ~6 % 랜덤 성분 [D §10.2]) · 부하 모양에 따라 치우침이 다를 수 있다 → 주 지표로 쓰지 않는다.
4. **작업량**: 에너지 C 는 같은 일로 맞췄지만 처리율이 런마다 1~2 % 흔들린다 → r 거름 [0.96, 1.04] · ΔE_adj 를 같이 본다. 기존 세기 A/B 는 B 가 일을 더 했다 (NPU r 1.06~1.10 · GPU 1.03~1.44 [D]).
5. 전압이 SOC 따라 내려간다 → 같은 쌍 안에서도 두 칸 전압이 다르다 (E_cc 는 갱신마다 그때 전압을 곱한다 — 남는 몫은 기술).
6. 시작 상태 · 앞 칸 · 시각 · 실내 온도 (거울 순서로 일부만 상쇄) — C1 은 낮 세션일 수 있다.
7. **화면 밝기**: 기존 런 (N1 · N2 · V3) 의 밝기 설정은 기록이 없다 (`미확인` — 10/2 M1 은 "밝기 0" [D `M1_결과_1002.md`]) · 자동 밝기면 칸 사이 화면 전력이 달라질 수 있다 → 에너지 B · V3 표에 적고, 에너지 C 는 §6-6 으로 고정.
8. 감시 adb 부하 (10 s 마다) · 화면 켜짐 — 두 팔에 같이 걸린다.
9. C1 · C2 두 세션을 합친다 — 세션별 표를 같이 둔다. 같은 세션 안 곱셈형 게이지 편향은 쌍 안에서 상쇄된다고 **가정**한다 [E, §10.3].

## 8. MEASUREMENT_DEFINITION §10 · §11 과 다르게 한 것 (이탈 명시)

- ③ 차이 검정: §10.3 은 두 조건 독립 표본 3·√(s₁²/n₁ + s₂²/n₂) — 이 등록은 **거울 순서 쌍의 쌍 차이** 로 3·SE (SE 에 양자화 바닥) + 한 눈금 바닥 + 동등 범위 (±2 눈금) 를 쓴다. 이유: 쌍 설계라 짝지은 차이가 맞고, 양자화된 차이는 표본 sd 가 0 으로 무너질 수 있다.
- ② 의 N < 8 세션은 σ_R 대신 §10.2 의 0.080 을 쓴다 (작은 N 에서 허용 폭이 우연에 좌우되지 않게).
- ②′ (팔 사이 일관성) 를 새로 더했다.
