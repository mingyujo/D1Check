## 6. 반대 해석 먼저 (ground-truth)

1. **Lb 가 Lk 보다 1항목 더 맞춘 것은 '부하 문턱' 기제 때문이 아닐 수 있다.** Lb 는 d10 에서 gate 를 무조건 풀므로 깊이 지도가 탐침 해제와 타협할 필요가 없어 D 가 1.23 (×2.23) 까지 올라갔고, 그래서 ⑪ 240~300 · ⑩ r2 · ⑫ r2 가 좋아졌다. Lk 는 κ_G 0.97 (m3 d50 에서) 로 d10 해제를 gate 로 내려다 D 0.93 에 머물렀다. 즉 차이는 **깊이 상한의 자유도**다 [E]. 오늘 밤 **G50P** 가 가른다: Lb(θ_GPU 0.3) 는 d50 탐침에서 "R50-none, 배율 1.5~1.6 으로 점진 하강" 을, Lk(κ 0.97) 도 "R50-none" 을 예측한다 — **둘 다 같은 예측이면 G50P 로는 못 가른다**; 가르는 것은 **N50P** (Lb θ 0.3 → none / θ 0.75 → fast · Lk κ_lo → slow 180 s (29.5) / none (30.5), κ_2·κ_inf → fast).
2. **파라미터를 늘려서인가** — 그렇다 (9 → 18). 늘어난 것: 셋째 계단 (a3·T3 → ⑬), 냉각 c (→ ⑫ 는 그래도 실패), 깊이 지도 W·D (v1 K·T_set·u_max 와 수가 같다), θ (고정). ⑨ 는 파라미터가 아니라 **형태 (u < θ 해제)** 가 냈다 — v1·V2-S 는 어떤 파라미터로도 못 낸다 (해제 온도가 진입 온도보다 높다).
3. **본 자료에 맞춘 것인가** — ⑨·⑬ 은 피팅 런 (a) 와 쌍둥이 런 (b) 로 확인했다 → 본 자료. 오늘 밤 NI300 (NPU 재조임) · N50P 가 처음 보는 조건이다.
4. **⑨ 를 "부하" 가 아니라 숨은 빠른 센서로** — NPU 자체 온도 (HAL 에 없음 [P 03_thermalservice_1.txt]) 가 부하를 내리면 10~20 s 안에 식고 SKIN·AP 는 느리게 식는다면, "u < θ 면 해제" 와 10 s 척도에서 **같은 예측**을 낸다. 수식으로 다른 점은 d50: 숨은 센서는 d50 에서도 (전력 반) 식어 해제될 수 있고 (R50-fast), θ 모형은 θ 값에 따라 둘 다 낼 수 있다 — **N50P 가 R50-fast 면 θ > 0.5 와 숨은 센서를 못 가른다** (같다고 적는다). R50-slow/none 이면 숨은 센서 가설은 "d50 전력으로는 안 식는 센서" 로 좁혀진다.
5. **GPU 구동 센서 = SKIN 이 뽑힌 것**은 사전 예상 [E] 대로지만, AP 목적함수가 3~4배 나쁜 이유는 AP 가 d100 가열 중 내려가서다 (42.8 → 41.0) — "AP 가 트리거" 인 가설 (H-ap-히스, 밤 사전 등록 §3) 과 이 모형은 **양립하지 않는다**. G50P 해제 칸 AP ≥ 40 이면 H-ap-히스 기각 (밤 규칙) — 이 모형은 해제 자체를 예측하지 않는다 (R50-none).
6. ③ 실패가 형태 탓인지 런 간 편차 탓인지 — 1계단 실측 5런 150~300 s, 모형 −60~−70 (n1300 기준 240 vs 300) · m1n_a 0 · m1n_b −10. 10/3 두 런은 맞고 10/2 세 런은 틀린다 → **런 간 가열 속도 편차 (시작 BAT·잔열) 가 모형 오차보다 크다** — 형태로 고칠 문제가 아닐 수 있다 [E].
