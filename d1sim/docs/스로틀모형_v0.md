## 1. 한 줄

**SKIN 구동 2노드 모형(M-A2)** 이 r1 에 맞춘 파라미터로 r2 의 진입(−10 s)·평형 지연(+2.0 %)·지연 궤적(MAE 0.33 ms)·전력 궤적(MAE 0.29 W)·SKIN(MAE 0.13 ℃)을 따라간다. 1노드 형태 2개와 AP 구동 2개는 스로틀 자체를 못 내거나 부호가 반대라 기각. 600 s 를 넘는 구간은 **아직 아무 자료로도 검증 안 됨** — 오늘 밤 C1a 가 진짜 홀드아웃이다.

## 2. 모형 (채택: M-A2)

[E — 형태는 일반 지식(1차 열 동역학·DVFS 전력)에서 가져왔고 논문 근거 없음. 파라미터 값은 r1 피팅 [P-fit]]

```
s        = clip(1 − k·(T_SKIN − T_th), s_min, 1)        스로틀 계수 (정적 비례 지도)
지연      = L0 / s
전력      = P_idle + (P0 − P_idle) · s^α
τ_f·dH_f/dt = G_f·(P − P_idle) − H_f                     빠른 노드
τ_s·dH_s/dt = G_s·(P − P_idle) − H_s                     느린 노드
T_SKIN   = T_start + H_f + H_s
```

기제 [E]: 빠른 노드가 SKIN 을 ~55 s 에 T_th 위로 올리면 s 가 줄어 전력이 준다. 느린 노드는 그 뒤에도 수백 초 동안 쌓이므로, SKIN 을 거의 같은 값에 유지하려면 빠른 노드 몫(= 전력)이 계속 줄어야 한다 → **"SKIN 은 평탄한데 지연은 계속 오른다"** 를 낸다. 1노드로는 이 관측을 낼 자유도가 없다.

## 5. 오늘 밤 C1a (진짜 홀드아웃) — v0 의 예측을 지금 적어 둔다

v0 를 그대로 1800 s 돌린 값 (60 s 구간 평균, `d1sim/throttle.py:simulate_continuous`) [E-모형]:

| 시작 SKIN | 300 s 지연 / 전력 / SKIN | 600 s | 1200 s | 1800 s |
|---|---|---|---|---|
| 30.3 | 6.25 ms / 3.23 W / 38.15 | 6.70 / 2.97 / 38.26 | 6.72 / 2.95 / 38.27 | 6.72 / 2.95 / 38.27 |
| 31.1 | 6.64 / 3.00 / 38.28 | 7.10 / 2.77 / 38.39 | 7.13 / 2.75 / 38.39 | 7.13 / 2.75 / 38.39 |

- v0 는 **~600 s 에서 평형**, 600→1800 s 지연 +0.4 % 로 예측한다. C1a 가 600 s 이후 계속 느려지면 → 느린 노드가 하나 더 있거나(τ_s ≫ 293 s) 제어기가 적분형이라는 뜻 → v1
- **시작 온도 민감도가 크다**: 시작 SKIN 1.3 ℃ 차이가 평형 지연 10 % 차이 (T_start 를 주변으로 취급하는 가정 때문 [E]). C1a 비교 때는 C1a 의 실제 시작 SKIN 행을 쓴다
- C1a 로 비교할 지표 (사전 등록 §4 와 같음): 진입 오차 · 평형 지연 오차 (마지막 60 s) · 지연·전력 MAE · SKIN MAE. **v0 를 고치지 않는다**
