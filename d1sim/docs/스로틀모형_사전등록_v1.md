## 2. 구조 후보 (이름을 미리 붙인다 — 출발점이지 정답이 아니다 [E])

공통 — **공유 열 상태** (어느 자원이 돌든 그 자원의 전력이 같은 상태를 데운다), 전력 `P = P_idle + (P0_r − P_idle)·s_r^α_r` (실행 자원 r; idle 이면 P_idle; v0 ALPHA 형태 유지 [E]):

```
τ_f·dH_f/dt = G_f·(P − P_idle) − H_f        τ_f = 34.4 s 고정 [D 평가층_사전등록_v1:47]
τ_s·dH_s/dt = G_s·(P − P_idle) − H_s        τ_s 피팅
SKIN = T_start + H_f + H_s
τ_a·dH_a/dt = G_a·(P − P_idle) − H_a        τ_a = 17.0 s 고정 [D 같은 곳:49]  (AP 가 SKIN 위에 더 빨리 뜨는 몫)
AP   = SKIN + A_0 + H_a                      A_0 = 런 시작 (AP − SKIN) [P 런별 1 s 행 0; 프로파일 기본 −1.0]
```

| id | 트리거 센서 | 자원별 스로틀 (s_r = 1 − u_r) | v0·0927 과 무엇이 다른가 |
|---|---|---|---|
| **M-P** (설정점 제어기형, 주 후보) | **AP** (빠른 노드) | 진입: AP ≥ T_on_r 이 **d_on = 10 s** 이어지면 arm [E, T7 관측: 뜨거운 시작 첫 10 s 가 식은 속도] · arm 중 **du/dt = K_r·(AP − T_set_r)**, u ∈ [0, u_max_r] (적분형 깊이) · 해제: AP < T_off_r 이면 u → 0 **즉시** (계단, T3·M1 관측) | 0927 기각 M-B1·B2 는 **정적 지도** s = f(AP) 였다 — AP 가 내려가면 s 가 올라가야 해서 부호가 반대였다. | M-T (타이머 해제형) | AP 진입 / 고정 지연 해제 | M-P 와 진입 같고 해제가 "arm 뒤 t_rel 초" | **이번엔 시도 안 함** (M1 1런으로 AP 문턱 해제와 타이머 해제를 못 가른다 [D M1_결과 §1] — 오늘 밤 M1-NPU R-fast/R-skin 이 가른 뒤) → 원장에 "미시도" |

**NPU** (M-P·M-S 공통, 이산 2계단 + 점진 [P N1300 §3 모양]): `ratio_N = 1 + a1·[arm1] + a2·[arm2] + min(K_N·∫_{arm2}(T − T2_N)^+ dt, u_cap_N)`, arm_i = T ≥ T_i_N 이 d_on 이어짐. 해제 = 변형 R-fast (T < T_off_N → 0) / R-skin (SKIN < T1_skin_N → 0). s_N = 1/ratio_N.

**전환비용 표** (⑧, 열 모형 아님 — 프로파일 `switch_cost_s` 에 온도 함수 두 값 + 출처): GPU→NPU 식음/뜨거움 0.137~0.147 / 0.183~0.196 s (model_init 21~32 ms) · NPU→GPU 식음 0.396~0.417 (init 283~287) / 뜨거움 0.803~0.808 s (init 611~613) [P M2_결과 §1·§2] · idle→NPU 0.111 (P1 유지) · idle→GPU 0.273 (CompiledModel 식음 init 283~287 ms 와 겹침 [P]) · idle→CPU4 0.031 [D]. ## 3. 피팅 방법 (결정적, 난수 없음)

1. **A 열 상태**: 실측 1 s 전력 P(t) 를 입력으로 넣고 SKIN(t) 를 맞춘다 (G_f · G_s · τ_s; 목적함수 = 1 s SKIN 오차² 평균, 피팅 런 합동). AP 는 그 뒤 (G_a; A_0 는 런별 초기값). Nelder-Mead 고정 시작점
2. **B 제어기 (자원별)**: 실측 AP(t) (M-S 는 SKIN(t)) 를 입력으로 제어기를 돌려 10 s 칸 배율 r(t) 를 맞춘다 (T_on · K · T_set · T_off [· u_max]; NPU 는 T1 · T2 · a1 · a2 · K_N). 목적함수 = 10 s 칸 배율 상대오차² 평균. 격자 + Nelder-Mead 고정 시작점. **T_off 는 해제 자료가 있는 GPU(M1 탐침)만 피팅**, NPU·CPU 는 `미확인` → 변형
3. **C 닫힌 고리**: A+B 를 합쳐 전력 → 열 → 제어기 → 전력 으로 런 전체를 돈다 (T_start·A_0·duty 위상 = 실측). **여기서 §4 체크리스트와 §5 오차 기준을 판정**한다. B 단계 오차(측정 AP 입력)는 보고만
4. 전력 α_r: v0 와 같은 log 회귀 (10 s 칸, s ≤ 0.95) — 자원별

## 6. 규칙

- **같은 방향 3번**: 한 형태를 같은 방향으로 3번 고쳐도 §4 를 못 맞추면 그 형태를 버리고 원장에 "무엇이 무엇을 망가뜨렸다" 한 줄

- "AP ≈ 42" 류 해석은 [E] 사후 가설 — 이 자료로 만든 가설은 이 자료로 검증 못 한다. 검증 = 오늘 밤 (2-5 예측 동결)
