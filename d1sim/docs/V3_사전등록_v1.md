## 5. 판정 (조건마다 · 지금 고정)

**③ 열 반응 (v2 §9-5 그대로)**: Δ_k = 기준선 최고 SKIN − ours 최고 SKIN (블록 k)
- 두 블록 모두 Δ_k ≥ +1.0 ℃ → **"BG 재생 열 반응 같은 방향 (기준 넘음, 작업량 비 r)"**
- 두 블록 모두 > 0 · 하나라도 < 1.0 → "같은 부호, 기준 안"

- 어느 블록이든 r < 0.95 → "작업량 차 큼 — 비교 기술만" (위 판정 대신)

**④ 모형 전이 (G1 문서 §5 그대로)**: 두 블록 모두 (예측 Δ 부호 = 실측 Δ 부호) **그리고** |예측 Δ − 실측 Δ| ≤ 1.0 ℃ → **"전이 확인 (V3 · 1밤 · 2블록)"** · 아니면 "전이 미확인 유지". 예측 = §6 동결값 (그 블록 두 런의 실제 시작 SKIN 평균에 가까운 열 — 보간 없음). 판정은 주 모형 v2.2 로 · 민감도 (v2.1 · v2 θ0.3 · θ0.75) 는 나란히 기술.

**결론 표 (v2 §3) 로 옮기기 — 조건마다**
- ③ "같은 방향 (기준 넘음)" + ④ "전이 확인" → **1행**. 조건 A 는 1행이어도 문장 끝에 **"가족 대조군 (늘 d50) 도 시뮬에서 같은 이득 — 기한 인지 규칙 고유의 효과라고 쓰지 않는다"** 를 붙인다.

- 두 조건의 행이 다르면 둘 다 그대로 (평균 안 함).
