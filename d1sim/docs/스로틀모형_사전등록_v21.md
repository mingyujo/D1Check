```

### 2.2 V21-F (빠른 노드 — "숨은 빠른 센서")

```
자원별 빠른 노드: τ_F·dF_r/dt = g_F,r·(P − P_idle)·[r 실행 중] − F_r      (τ_F 격자 {10, 20, 40, 60} s, g_F,r 피팅)
