# 현재 실측으로 비용 민감도・온도 변화를 보정한 새 개발35

2026-10-13 착수, 2026-10-14 완료. 기존34/27/28과 원자료・ZIP・중지된 다른27 학습은 보존했다. 사용자 목표는 스케줄링별 에너지・열・납기 차이를 드러내는 것이다. 계수는 더 큰 정책 격차로 선정하지 않고, 기존 실측을 제외한 코호트에서 예측 오차/변화폭/방향/최악 손해로 선정했다. 본 작업에는 새로운 폰 실측・독립 확인・학습이 없다.

## 수정 결과

- A24와 S26에 각기 다른 현재 자원 점유 상태와 최근20초 실행 비율의 후보를 구현했다. CPU/GPU/NPU 칩 전력의 분해로 해석하지 않는 유효모형이다. 전력의 완전 교체・기저 보정・보수적 혼합 모두 검토했지만 정책 ΔJ나 최악 세션 손해를 함께 줄이는 후보가 없어서 원전력을 유지했다. 전력 수정 실패도 POWER/BASELINE_FOLLOWUP/POWER_MIX에 모두 보존했다.
- 온도는 A24의 기존 초기열을 보존한25% 최근부하 응답 혼합, S26은 기존27과 새 자원상태 응답의50% 혼합을 별도 개발 후보로 채택했다. 모형 이름・식은 기기별이고 계수를 서로 옮기지 않았다. 새 전력과 완전한 물리 에너지 보존 열모형이라는 주장은 하지 않는다.
- S26 M6 1200요청의 온도 조건 실행시간 후보4경로를 검토했다. 온도・시간 위치 상관과 최악 오차 또는 제외 코호트의 이득이 불안정해0개 채택했다. A24의 현재 5단계 분류CPU 서비스풀은4표본이고, 더 많은 과거 점유 이력은 전력/열 적합에 사용했다. 과거와 현재 APK는 다르며 core signature 일치가 전체 측정조건 동일이나 실행단계별 감속 전이를 보장하지 않는다. 중간 실행의 열 DVFS・병행 감속・시동・유휴 tail을 새로운 실측 법칙으로 넣지 않았다. 실제 감속을 임의 키워 격차를 만들지 않는다.

## 근거 있는 데이터와 미확인 가정

실측 근거: A24 과거35전력/39온도 세션, S26 현재 APK M6 P12/K4와 요청1200개・실제AVAILABLE・내부 gauge/센서 단위. 모든 원본 SHA 보존. 지원/품질 근거는 기존 계약을 재사용했으며 새 검증이 아니다.

통계적 가정: 현재 점유 상태를 다른 요청열로 옮김, 최근20초 basis, 기존 빠른/느린 열 시간상수와 초기열의 전이, 고정 서비스 표본 재사용, 합성 도착/여유납기, 원PPO 전이. 시간상수・선형 근사・혼합비는 개발 모형 설정이지 식별된 DVFS나 chip W가 아니다. 새35에31의6/7W・.65/1.2/1.35 시간배율・8/70초 열 저장소・임의 시동/감속을 넣지 않았다.

범위 밖: 장시간 CPU 감속의 현재APK 재현, 자원별 독립 전력 식별, 초기 내부열의 유일한 복원, A24 SKIN, 새 요청 분포의 실기기 정확도, 추론 정책의 휴대폰 소비/판단시간. 추가 실측 없이 해결했다고 쓰지 않는다.
