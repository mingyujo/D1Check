## 왜 격차가 생기는가

빠른 CPU를 계속 쓰면 실행 전력과 열이 쌓이고 뒤의 작업이 느려진다. GPU/NPU를 쓰면 전력 비용은 낮지만 실행시간과 CPU 탐지 병행 선택이 달라진다. FIFO·SPT·EDD·ATC·RR·고정 선호 자원 Greedy·PPO는 서로 다른 작업/자원을 선택하므로 비용과 납기가 달라질 수 있다. 모든 정책이 같은 행동을 한 조건은 동률로 남긴다.

추가W뿐 아니라 탐지 실행 구간·최근 감속·CPU 전환·열 계수를 함께 바꿨다. 따라서 확대 결과는 복합 환경 변화이며 추가W 단독 효과가 아니다. startup/switch 순간J는 에너지에 부과하지만 별도 순간 열 입력은 추가하지 않았고, 새 EXECUTING 전력과 기존 연속 추가 전력만 열 방정식에 함께 들어간다.

PPO는 새 환경에서 학습한 모델이나 자원별 추가W를 사전에 알고 있는 모델이 아니다. 원 학습 ABI와 고정 가중치를 유지했고 .9초 전력·2초 온도 관측을 사용했다. 짧은 실행 전력 비용을 행동 전에 구분하기 어려운 경우도 있다. 격차를 키운 효과와 PPO 우위·새 학습 효과는 구분한다.

전체672환경/96조건·2개 도착 난수를 보존했다. 새 정책학습/native/Adam/fit/기기/APK/외부전송0이다. 이전17~19의3,486환경과 결과·소스·가중치는 보존했다. PC 시간은3개 독립 worker 영향이 있어 이전 단일 worker 또는 휴대폰 비용과 직접 비교하지 않는다.

전체 정책/조건 표와 비용 분해는 policy_summary.csv/case_spread.csv/tier_spread.csv, 실행 코드는 repro/에 있다. 알려진 미완료와 악화 사례도 같은 분모로 포함했다. 파라미터를 실제 휴대폰 측정값으로 취급하지 않는다.

패키지의 고정 PPO 실행2회도 기존 최종 원장·사건·비용·냉각과 정확히 재현했다. 이번 신규 실행은 코어672+패키지2=674회이며 신규학습0이다. 원본/패키지의 합성 단위 검사12개씩도 통과했다.

새 설정에서 EDD/ATC의 실행 원장도 A24 16/16조건, S26 9/16조건에서 달랐다. 순위 차이와 실제 실행 차이는 별도 CSV로 구분했다.
