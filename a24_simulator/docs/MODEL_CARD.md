# 공통 A24 모형

하나의 사건 엔진이 동일한 공개 요청을 각 정책에 전달합니다. 동일 기기의 실측 처리 벡터를 latent work로 표본화하고, 현재 공개 점유 상태에 따라 남은 진행률을 갱신합니다. 완료된 과거 phase는 다시 쓰지 않습니다. 같은 seed는 정책간 공통 잠재 표본의 키이며 미래 값을 정책 관측에 공개하지 않습니다.

## 처리시간·병행

원 통합 timing support는 기존+M8 자료에서 task/route/protocol/device/model/input와 호환 문맥을 구분합니다. exact binding을 보존하면서 bank 전용을 허용하는 경우 별도 표식이 있습니다. CG/DC의 측정 지원과 그 외 조합의 독립 서비스 외삽을 구분합니다. D_GPU는8개 과거 paired stage 비율·2개 역할 세션에 기초한 전이입니다. 독립8세션으로 부풀리지 않습니다.

## 열

초기 실제 AP·관측 가능한 이력·실행 활동에 기반한 모형입니다. 주변온도와 통계적 평형은 같은 뜻이 아닙니다. 새 경로 계수는 이전3경로 모형의 작업/장치 가산 외삽이며 새 적합의 식별 가능성 진단을 가장하지 않습니다. inherited rank/iteration은 원 적합 범위의 메타데이터입니다. 새 온도→처리시간 피드백은 미식별입니다.

## 에너지

`J*=baseline_W×공통창길이+Σ(state_increment_W×state_seconds)`입니다. 서로 다른 정책에 같은 식을 적용합니다. 같은 경로·점유·겹침이면 순서/WAIT만 바뀌어도 J*가 같을 수 있습니다. 이것은 모델의 조건부 성질이며 실제 단말의 에너지 동일성 검증이 아닙니다. 전체 기저를 없애거나 미검증 온도 전력 계수를 추가하지 않습니다.

전체0~180초 지표와 입력으로 미리 정한 작업창 지표를 모두 저장합니다. 각 정책의 종료시각을 각자 에너지창 끝으로 삼지 않습니다. 일이 덜 끝났거나 이후로 밀린 경우 완료/미완료·납기·자원 반환을 함께 보고합니다.

## 정책

ATC는 공개 명목 처리시간·우선순위·기한에서 후보를 정합니다. PPO는 요청·지원 자원·WAIT 중 마스크가 허용한 행동만 선택합니다. 새4경로 학습과 과거3경로 actor 전이를 UI에서 분리합니다. DEV 선정 기준은 미완료 → 긴급/일반 서비스 목표 부족 → 조건부J* → 평균AP의 사전 고정 순서입니다. 평가 결과로 재선정하지 않습니다.

물리 모형은 이번 정책 재학습 중 동결했습니다. 원115 자료를 다시 써서 RL에 유리한 열/에너지 계수로 조정하지 않았습니다. 새 경로·병행의 실제 계측 근거가 추가되면 별도 세대에서 모형을 보완해야 합니다.
