## 기록 시점의 정확한 범위

REPORT.md 말미의 “후처리 소스/정의는 평가 전에 추가 등록”은 **분석·수치 감사·그림·원목표 판정 정의**에 한정한다. 명령·HEAD·출력SHA를 남기는 실행 기록 드라이버는 대조 실행 중에, 환경 버전의 UTF-8 기록 수정은 실험 종료 후에 별도로 등록했다. 이 후처리 추가 사항이 평가 전에 모두 고정됐다는 뜻은 아니다. 시뮬레이터·물리 계수·학습·선정·평가식·분석 기준은 결과를 보고 바꾸지 않았다.

환경 버전 기록1회는 Windows 기본 cp949로 UTF-8 한글 경로를 읽어 실패했다. [실패 기록](ENVIRONMENT_CAPTURE_FAILURE_01.json)을 보존하고 별도의 UTF-8 도구로 [환경 정보](ENVIRONMENT.json)만 기록했다. 시뮬레이션 재실행0이며 수치 검산에는 영향이 없다. [검증 명령·시점·버전·출력SHA](verification_receipts.jsonl)에 실패와 수정된 별도 단계가 함께 있다.

원 보고서·최종 증거는 수정하지 않았다. [2,599파일의 원 최종 증거](FINAL_HANDOFF_PROOF.json)와 이 안내의 추가 SHA는 PUBLICATION_ADDENDUM.json으로 연결한다. 완료된 실험은 다시 실행하지 않는다.
