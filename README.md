# D1Check

온디바이스 AI 요청의 자원배정·스케줄링을 다룬 산업공학 프로젝트입니다.
A24·S26 측정 자료로 기기별 시뮬레이터를 만들고, 롤링 예측·ATC·교사규칙·행동모방학습(BC)을 적용해 FIFO·EDF·RR과 비교했습니다.

[발표자료 PDF](presentation/발표자료.pdf)

## 결과

| 기기 | 정책 | 전체 정시 | 긴급 정시 | EDF 대비 예측 소비 | EDF 대비 평균 AP |
|---|---|---:|---:|---:|---:|
| A24 | 롤링+ATC+안전여유 보완 교사규칙 | 2,048/2,048 (100%) | 1,280/1,280 (100%) | 1.14% 감소 | 0.248℃ 감소 |
| S26 | 롤링+ATC+BC·서비스 보완 | 3,976/4,096 (97.07%) | 2,560/2,560 (100%) | 7.68% 감소 | 0.770℃ 감소 |

A24는 입력당 512건·8건 묶음·명목 부하 25%, S26은 1,024건·16건 묶음·85%에서 각각 4입력을 평가했습니다. 납기와 집계 기준은 같고, 입력 규모와 지원 자원은 다릅니다.

발표자료 13·14쪽의 A24 BC 100% 표기는 저장 결과와 차이가 있습니다. 같은 최신 입력에서 BC는 전체 2,047/2,048건(99.9512%), 긴급 1,279/1,280건(99.9219%)입니다. 위 표의 100%는 보완 교사규칙 결과입니다. [수치별 근거와 정정 사항](docs/RESULT_SOURCES.md)

소비는 모형 예측값(A24 J*, S26 API-J)입니다. A24 보완 교사는 명목 부하 50%에서 전체 정시율 70.90%였으며, 주 조건의 일반 P95는 EDF보다 0.055초 길었습니다. S26 주 조건의 긴급 P95는 0.634초로 EDF의 0.340초보다 길었습니다. [평가 조건과 한계](docs/EVALUATION.md)

## 자료 구성

- `presentation/`: 발표자료 PDF
- `a24/`, `s26/`: 기기별 측정 앱, 시뮬레이터, 정책, 입력과 결과
- `data/`: 공개 파일 목록과 대용량 데이터 다운로드 정보
- `tools/`: 데이터 복원·결과 검산 도구

## 데이터와 검산

```bash
git clone https://github.com/mingyujo/D1Check.git
cd D1Check
python tools/fetch_data.py
python tools/verify_submission.py
```

Python 3.11 이상을 사용합니다. 큰 데이터는 [릴리스](https://github.com/mingyujo/D1Check/releases/tag/submission-data-20261022)에서 내려받습니다. 검산은 파일 해시와 저장 원자료의 집계를 확인하며, 새 실험이나 학습을 실행하지 않습니다.
