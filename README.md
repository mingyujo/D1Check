# D1Check · 온디바이스 AI 작업 스케줄링

스마트폰의 여러 AI 요청에 대해 **무엇을 먼저, 어느 실행 장치에서, 언제 처리할지** 결정하는 프로젝트입니다. A24·S26의 측정 자료로 기기별 시뮬레이터를 구성하고, 롤링 예측·ATC·교사규칙·모방학습(BC)을 이용한 정책을 FIFO·EDF·RR과 비교했습니다.

## 발표 자료와 읽는 순서

- [제출 발표 PDF · 버전 1](presentation/제출본_버전1.pdf)
- [후속 결론 문구 PPTX](presentation/updates/결론_문구수정.pptx) · [교사·BC 행동선택식 PPTX](presentation/updates/교사_BC_행동선택식.pptx)
- [평가 기준·기기별 차이·해석 범위](docs/EVALUATION.md)
- [발표 수치와 저장 원자료의 대응](docs/RESULT_SOURCES.md)
- [자료 내려받기·읽기 전용 검산](docs/REPRODUCTION.md)

PDF는 전달받은 파일 그대로이며, 두 수정 슬라이드는 별도 파일입니다. PDF의 A24 100%와 BC 표기를 함께 읽을 때는 아래 구분을 확인해 주세요.

## 저장 결과의 핵심

| 구분 | A24 최신 100% 참고 결과 | S26 발표 결과 |
|---|---|---|
| 정책 | 롤링+ATC+안전여유 보완 **교사규칙** (`TEACHER_MATCH`) | 롤링+ATC+BC, 경로·일반 요청 서비스 보완 포함 |
| 주 평가 입력 | 512건 × 4입력, 8건 묶음, 명목 부하 25% | 1,024건 × 4입력, 16건 묶음, 명목 부하 85% |
| 전체 정시 | 2,048/2,048 · 100% | 3,976/4,096 · 97.07% |
| 긴급 정시 | 1,280/1,280 · 100% | 2,560/2,560 · 100% |
| EDF 대비 예측 소비 | 1.14% 감소 | 7.68% 감소 |
| EDF 대비 평균 AP 온도 | 0.247℃ 감소 | 0.770℃ 감소 |

**A24의 100%는 BC의 결과가 아닙니다.** 같은 최신 입력의 기존 BC는 전체 2,047/2,048건(99.9512%), 긴급 1,279/1,280건(99.9219%)입니다. 앞선 다른 draw의 BC 결과는 전체 99.8535%였습니다. 입력·정책이 다른 수치를 합쳐 쓰지 않습니다. 최신 교사규칙 비교는 저장된 사전 비교군의 결과이며 기본 정책의 자동 채택을 뜻하지 않습니다.

소비는 A24의 미교정 모형 예측값 **J\***, S26의 API 전력 모형 적분값 **API-J**입니다. 실기기 배터리 절감량으로 인증한 값이 아닙니다. 두 기기의 절대값으로 기기 성능을 순위 매기지 않습니다.

## 함께 확인할 상충관계

- A24 보완 교사는 주 조건에서 100%였지만, 명목 부하 50%에서는 전체 726/1,024건(70.8984%)이 정시였습니다. 주 조건의 일반 응답 P95도 EDF보다 약 0.055초 길었습니다.
- S26 주 조건의 긴급 응답 P95는 우리 정책 약 0.634초, EDF 약 0.340초입니다. 긴급 기한 0.8초를 지켜도 응답이 더 빨라진 것은 아닙니다.
- S26 확장 32입력의 EDF 비교에서는 28입력에서 소비·평균 온도가 낮고 서비스 지표가 악화되지 않았습니다. 명목 105%·32건 묶음·분류 75%의 4입력에서는 소비·온도가 높고 긴급 정시율이 낮았습니다. 전체 32입력 자료를 함께 보존합니다.

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `presentation/` | 제출 PDF와 최근 수정 슬라이드 |
| `a24/benchmark-runner/`, `s26/benchmark-runner/` | 측정 앱·수집 코드 및 빌드 자료 |
| `a24/a24_simulator/` | A24 측정 자료, 모형·정책 코드, 입력·체크포인트·저장 결과 |
| `s26/s26_simulator/` | S26 모형·정책 코드, 입력·체크포인트·저장 결과 |
| `data/FILES.json` | 공개 자료별 경로·크기·SHA-256·저장 위치 |
| `data/ASSETS.json` | 대용량 공개 데이터 ZIP의 해시·다운로드 주소 |
| `tools/` | 데이터 복원과 저장 결과 검산 도구 |

512KiB를 넘는 데이터는 [공개 데이터 릴리스](https://github.com/mingyujo/D1Check/releases/tag/submission-data-20261022)에 있습니다. Git 코드와 릴리스 데이터를 합쳐 원래 상대 경로를 복원합니다.

```bash
python tools/fetch_data.py
python tools/verify_submission.py
```

위 명령은 기존 자료를 내려받고 검산합니다. 새 시뮬레이션·학습·실기기 실험을 실행하지 않습니다. Python 3.11 이상과 표준 라이브러리만 필요합니다.

기존 전체 Git 이력·초안·개발 보고서·발표 중간 산출물은 소유자 전용 `Backup_2026`에 보존했습니다. 공개본에도 발표 결론에 필요한 비교군·실패/악화 조건·모형 가정·원자료를 남겼습니다. 모델·APK·서명 바이너리의 재배포 범위는 [별도 안내](docs/THIRD_PARTY.md)를 확인해 주세요.
