# 저장 자료 복원과 검산

Python 3.11 이상을 사용합니다. 다음 도구는 표준 라이브러리만 쓰며, 시뮬레이터·신경망·학습 코드를 import하거나 실행하지 않습니다.

```bash
git clone https://github.com/mingyujo/D1Check.git
cd D1Check
python tools/fetch_data.py
python tools/verify_submission.py
```

`fetch_data.py`는 공개 릴리스 ZIP의 SHA-256을 확인하고, 각 파일의 크기·해시를 확인한 뒤 매니페스트의 상대 경로로 복원합니다. 기존 파일이 다르면 덮어쓰지 않고 중단합니다. `--match a24/` 또는 `--match s26/`로 복원 대상을 좁힐 수 있습니다. ZIP은 `.data-cache/`에 재사용합니다.

`verify_submission.py`는 다음을 확인합니다.

1. 공개 코드·입력·체크포인트·원자료·발표 파일의 크기와 SHA-256.
2. A24 최신 PRIMARY의 9정책×4입력 원시 요청에서 정시율·미응답·미완료·입력별 P95와 예측 소비·온도를 다시 집계.
3. S26 4방법×4입력의 원시 요청에서 서비스 지표와 저장 적분값을 다시 집계하고 발표 집계와 대조.
4. A24 교사 100%와 BC 99.9512%의 구분, A24 고부하 70.8984% 및 S26 긴급 P95 증가 확인.

이는 저장된 결과의 무결성·산술 재현입니다. 시뮬레이터의 실제 기기 정확성을 검증하는 실험이 아닙니다. 파일 복원을 생략하면 검산은 누락 파일을 알리고 실패합니다. `--hashes-only`는 파일 무결성만 확인합니다.

## 원 시뮬레이션 코드

A24 Python 소스는 `a24/a24_simulator/experiments/`와 `src/`, S26 Node/Python 소스는 `s26/s26_simulator/experiments/`와 `src/`에 있습니다. 실행 입력, 모델, 체크포인트, 평가 계약은 각 실험 폴더의 JSON에 고정되어 있습니다. 원 코드의 상대 경로를 보존하기 위해 두 기기 디렉터리를 분리했습니다. 과거 절대 경로가 들어 있는 출처 메타데이터는 당시 기록이며, 현재 자료의 위치는 `data/FILES.json`을 기준으로 찾습니다.

새 학습·시뮬레이션은 본 검산 절차에 포함하지 않습니다. 과거 실행기를 새 환경에서 실행하려면 해당 세대의 의존성·경로·실행 계약을 먼저 확인해야 하며, 결과 파일을 덮어쓰지 않아야 합니다. 오래된 package script나 CLI가 현재 공개본의 모든 과거 세대를 자동 복원한다고 보장하지 않습니다.

측정 앱의 소스와 Gradle 자료도 보존했습니다. APK·서명키·제3자 추론 모델은 포함하지 않습니다. 원시 측정 ZIP과 객체형 데이터는 공개 릴리스에서 같은 경로로 복원합니다.
