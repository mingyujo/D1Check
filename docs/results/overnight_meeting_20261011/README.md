# 오전 회의용 오프라인 연구 브리핑

[index.html](index.html)을 브라우저에서 열고 화살표로 핵심10장을 이동한다(약10분). 부록 포함 버튼은 전체19장, N은 발표자 노트, 인쇄는 전체 슬라이드다. 외부 라이브러리·네트워크 없이 열린다.

새 비교 자료의 평균 감소와 엄격한 원판정 미달을 함께 보여준다. 기기 재생은 온라인 정책 효과가 아니며, AP는 표면온도가 아니다. 완료되지 않은 결과를 완료로 표시하지 않는다. 원사용자 모형 원본은 공유하지 않고 최소 수치·원source SHA를 따로 추출했으며 실제 동결 모형은 기존 공유 model.json을 참조한다. 사후96환경 진단은 부록이며 새 독립 확인이 아니다.
