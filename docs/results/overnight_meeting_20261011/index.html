질의응답 ①

산업공학 기여는 무엇인가?

납기 순서·예상 점유·자원 호환성·제약·rolling horizon을 앱 내부 비선점 CPU/GPU 배정에 대응하고 실제 근거로 평가했다. 새로운 일반 최적 알고리즘을 입증한 것은 아니다.

왜 기본 정책이 좋은가?

검증된 자원이 적고, 빠른 자원 선택과 CPU/GPU 병행이 이미 많은 이득을 만든다. 예측 위험·미관측 미래를 고려하면 남은 안전한 차이가 작다.

RL을 실제로 돌렸나?

3seed 각각512에피소드·64update·Adam768step의 masked PPO를 실제 학습했다. 기존32에서 같은 최종 actor/critic/Adam/RNG를 이어 추가1440에피소드를 수행했다. 개발 동률이 새 확인에서 일반화되지는 않았고 세 seed 모두 원 기준 미달이다.

얼마나 돌리면 수렴하나?

정해진 횟수만으로 수렴이나 전역 최적을 보장할 수 없다. 학습량 효과는 비단조일 수 있다. 복수 seed·학습량별 원 KPI의 안정성과 확인 자료를 본다. NoWait는 냉각·자원 대기를 둘 다 제거한 진단이다.
