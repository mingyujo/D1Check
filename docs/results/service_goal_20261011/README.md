# 서비스 기준 정렬·새 PPO·과제약 보완 결과

**실험과 수정은 완료했지만, 전체 조건에서 서비스와 열·에너지를 함께 만족하는 우위는 아직 입증하지 못했다.** 기본 정책을 교체하지 않았다. [오프라인 요약 화면](index.html)과 [원 단위 성적표](comparison.csv)를 먼저 확인한다.

## 실제 수행한 수정

1. 자체 공동 리스트 `JointList`를 기본·복귀·예측 후속·학습 참조로 구현했다. 도착한 큐의 호환 EDD CPU/GPU 배정안을 최대 네 개 비교하는 근사다. Band는 비교군이며 내부 기본으로 사용하지 않는다.
2. CPU/GPU의 물리적 실행 가능성과 예측 기반 성능 제한을 분리했다. 과거 L0의 개별 긴급 응답보다 느리다는 이유만으로 합법적인 GPU분류＋CPU탐지를 막던 제한을 제거했다.
3. 새 PPO 목적v2는 AP 주보상과 원 알고리즘·설정을 유지하면서 미완료/긴급/일반 실패를 절대 건수로 반영한다. 참조 초과 건수와 이중 합산하지 않는다. 새 schema/fresh weights로 각각64에피소드·8update·Adam96을 실행했다.
4. 비용 개선 예측 슬롯866개가 V1 서비스 제한 후0개로 줄어드는 문제를 찾았다. 그중273개는 개별 CPU-only 응답을 참조와 같거나 빠르게 유지하라는 항 하나로만 차단됐다. V2는 그 항을 기존 기한·실패·지각 조건으로 정렬하고 긴급 P95를 큐 소진 ECT보다 먼저 비교한다.

866/273은 저장 예측의 슬롯 수이며 독립 실험이나 실제 개선 횟수가 아니다. 대표 반례의 일반 요청 응답은0.25초 늦어도 기한 여유가 약5.13초이고, 예측 J 동일/AP 약0.02335°C 감소다. 아직 도착하지 않은21요청이 있어 전체 trace의 서비스 보장은 아니다. 현재 P95 보호 등 다른 예측 제한도 최종 전체 P95 조건과 완전히 같아진 것은 아니다.

새 PPO는 세 초기화 seed 모델을 round-robin으로 실행한 **공유 sampling RNG 세션**이다. 독립적인 세 샘플링 stream이나 세 완전 독립 반복으로 표현하지 않는다. 32/64 archive 여섯 개의 typed state 복원은 검증했고, 세 모델 전체의 동일한 중지·재개에는 공유 RNG와 `(case, nextseed)` 순서도 필요하다. 학습이 실제 작동한 것과 성능이 개선된 것은 별개의 사실이다.

835 별도 확인48에서는 Band 일반42/P95338.107524ms, Triton 일반39/P95372.576200ms다. CostV2는 일반45/P95364.197697ms로, Band 대비 평균 J−0.069924J/AP−0.004618°C를 얻었지만 일반 위반+3/P95+26.090172ms여서 원 strict FAIL이다. Triton 대비 일반 위반도+6이다. 개발24의 서비스 건수 유지가 새 확인의 서비스 보장은 아니었다. 833과835를 같은 자료의 전후 차이로 합치지 않는다.

현재 추천은 **기존 앱 기본 유지**다. 연구 발전 후보는 서비스·자원 호환성 기반 공동 롤링 리스트와 비용 선택이며, V2는 비용 감소와 서비스 손실의 상충을 드러낸 후보로 보존한다. 단순히 RL 학습량을 늘려 이를 해결한다고 전제하지 않는다. V1에서는 허용된 예측 AP/J 개선 후보 자체가0이므로 더 많은 학습만으로 새로운 행동을 만들어낼 수 없다.

## 데스크톱과 증거 범위

[데스크톱 이관 안내](../desktop_handoff_20261011/README.md)를 따른다. 실측으로 만든 A24 모형 안의 정책 비교를 PC에서 실행하는 것이며, 데스크톱의 실제 열·전력을 측정하는 작업이 아니다. 반복 평가와 RL 추가 학습은 다른 작업이다. 종료run의 시계·예산을 초기화하지 않고 별도 task·상한·seed·체크포인트를 등록한다. 변경된 V2의 의미에 V1 actor를 그대로 이어 학습하지 않는다.

모형 AP/HAL AP는 최고 표면 온도나 안전 한도가 아니다. J는 전류 해석을 전제로 한 전체 기기 적분 및 동결 계수이며 자원별 rail 측정이 아니다. 냉각에 따른 처리속도 회복·온라인 후보 예측/actor 제어 비용은 미지원이다. 미세 AP/J 차이는 실제 절감의 확정 근거가 아니다. 실측 범위를 넘는 행동을 추가하거나 미래 도착을 알려주지 않았다.

이번 대표96의 Band/Joint/Cost 계획은 같아 중복 실측을 하지 않았다. 오전 AP25.5°C는 개발 최초 AP 관측 최저25.9°C보다 낮아 지원 범위 내 효과 검증으로 표시하지 않았다. 새로운 다른 유망 일정, 관측/저장/품질 게이트와 판별 가능한 효과가 생겼을 때 대응 실측을 추가하는 것이 타당하다.
