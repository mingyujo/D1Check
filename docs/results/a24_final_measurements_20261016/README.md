## 무엇을 실제로 비교했는가

A24·동결 APK·동일 승인 이미지와 tensor·분류/탐지 모델을 사용했다. 분류C는 긴급(기존 고정 기한2.2초), 탐지D는 일반(5초)이다. 기한은 이번 결과를 보고 만들거나 바꾸지 않았다. L64는1초 간격64건, C252는약0.3332초 간격 분류252건, M128은고정 혼합8건 묶음16회다. 요청 은행·도착·기한·SHA는 공개 계약에 있다.

| 조건 | 실제 판단 규칙·자원 |
|---|---|
| 저부하 직렬 / 병행 | 둘 다 FIFO·분류GPU/탐지CPU. 직렬은 전체1건, 병행은 검증된 두 lane의 동시 점유 허용 |
| 분류 CPU / GPU | 동일 분류252건의 고정 자원 선택. 두 조건 모두 직렬 |
| 혼합 BASE | FIFO·분류GPU/탐지CPU·직렬 |
| 혼합 ORDER | EDD, 동률은 도착→ordinal→ID. 자원은 BASE와 같고 직렬 |
| 혼합 PAIR_G | FIFO·분류GPU/탐지CPU·최대 두 lane. 사용 중인 head lane을 건너뛰지 않음 |
| 혼합 WAIT200 | BASE와 같고, 아직 대기하지 않은 각8건 group 앞에서200ms 대기1회. 도착·콜백이 선택한 대기를 취소하지 않음 |

**여기의 ORDER는 EDD 단독이며 EDD+ECT나 새 PPO를 실기기에서 실행한 비교가 아니다.** Band/Triton 전체를 실행한 비교도 아니다. 데스크톱 학습·기존 시뮬레이터·S26/NPU 작업은 변경하거나 재시작하지 않았다. 탐지의 MAIN 자원은 CPU이며, 공통 준비의 GPU 상주/워밍업을 탐지GPU MAIN 성능 평가로 바꾸지 않는다.

응답은 `response_complete`로, 자원 재사용은 실제 `lane_available`로 검증했다. 비선점이며 주파수/전력 제어·지원하지 않는 동시 실행은 추가하지 않았다. 이벤트·용량·시간 진행·전체 요청·출력은 원 검증기로 검사했다.

## 근거의 한계와 남은 항목

- **에너지 J는 미판정**이다. 전류·전압·전하량의 원값과 API 단위 가설 적분은 남겼지만, 현재 펌웨어의 단위 경로와 시간 응답/재현성 검증이 끝나지 않았다. counter와의 불일치가 단위 오류만으로 설명된다고 확정하지 않으며 ×1000/×1210 등 임의 보정·새 계수 학습은 하지 않았다. 원 동결 분석의 `API_uA_hypothesis_J`는 검증된 물리J가 아니다.
- **AP는 HAL 보고 채널**이다. 실제 표면 위치·독립 센서 갱신 나이·절대 교정은 미확인이다. 임의 물리온도 한도를 만들지 않아 한도 초과 시간도 미판정이다. 별도 전류 반응 진단은CPU 반응0.2~0.4초·GPU3회중1회 검출이어서 범용 센서 지연 상수로 쓰지 않았다.
- 일부 종료 꼬리의 AP 상승·다른 시스템 프로세스 관측은 [별도 진단](../../team/a24-measurement-revision02-20261015/remaining13_after_transport_failure_20261016/POST_MAIN_AP_RISE_DIAGNOSTIC.json)에 보존했다. 원인·인과관계를 확정하지 않았고 유리한 구간만 골라 원 판정창을 바꾸지 않았다.
- 이번8군의 사전 수치 예측·최종 예측 모형은 제공되지 않았다. 실측 후 모형을 맞추고 이자료를 독립 예측 정확도PASS라고 부를 수 없다. GEN002 참고 소스와 관측 결과는 구분한다.
- 스케줄러 판단시간과 별도 제어 에너지는 독립 계측되지 않아null이다. 출력검사는 고정 입력의 CPU 참조와 decoded 결과 허용오차를 비교한 것으로 새 데이터셋 정확도·전체 tensor 등가성 검증이 아니다.
- 이번 실행의 추가 APK 빌드/설치0, 데스크톱 학습 재시작0, S26/NPU 변경0이다. **실제 A24 측정은 수행했으며 기기 실행0인 작업이 아니다.** 보고서·공개 재계산·trace PC 검사는 기기 명령0이다.

남은 연구 과제는 설치 펌웨어의 전류 단위/시간 응답 확인, 원40의 실패·미실행을 원래 상태로 보존한 후속 설계 판단, 독립 자료를 남긴 예측 모형 검증, 새 정책의 동일 조건 평가다. 이를 위해 이번 종료 뒤 새 실측이나 본학습을 자동 추가하지 않았다. `experiment_ready=false`도 유지한다.
