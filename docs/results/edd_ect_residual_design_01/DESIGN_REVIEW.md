신경망·PPO 수치와 실행 배분은 제안이며, 이번 검증은 정책 성능 실험이 아니다. 정상 중지·재개 archive 구현은 옛 보존 기술을 사용할 수 있지만 새109/68 schema·세 참조·부분 batch에 대해 다시 검증해야 한다.

기존192 조건은 설계에 사용했으므로 새 미열람 평가라고 부르지 않는다. 향후 새 seed에서도 열·에너지 이득이 작으면 실측 모형의 오차와 적용 범위를 함께 보고한다. 다른 부하의 평균오차를 임의 안전 여유나 효과 합격선으로 전용하지 않는다.

추가 확인: EDD 기반 RL이 모든 순서·자원을 자유롭게 바꾸므로 실행 결과가 EDD에서 크게 벗어날 수 있다. EDD를 이용했다는 근거는 정확한 BASE·초기 prior·예측 suffix·비교 제거실험이며, 최종 선택 중 BASE 일치율/순서변경/자원변경/대기 변경 비율을 공개한다. EDD 원 규칙과 새 학습 정책을 동일 알고리즘으로 표시하지 않는다.
