## 구현과 먼저 고정한 목적

별도 정책 `ENERGY_AP_MC_RL_V1`은 **표 기반 first-visit episodic Monte Carlo control**이다. 신경망·새 의존성·APK 없이 기존 이벤트 실행기의 실제 결정 callback에 연결했다. 시행 후 전체 결과를 다음 결정의 가치 추정에 반영하는 강화학습이며, 정답 backend를 주는 지도학습이나 단순 정책 이름 변경이 아니다. DQN/PPO/CPO/MOPO 구현이나 이론적 수렴·제약 보장을 주장하지 않는다.

각 `(상태, 행동)`의 최초 방문마다 해당 에피소드의 종료 비용 벡터를 표본평균으로 갱신한다(할인1). 탐색 확률은 등록된 96회 동안0.30→0.05, 평가에서는0. 평가 전 마지막 표만 동결한다. 학습 중 최선 checkpoint 선택, hyperparameter 검색, 평가 결과를 본 재학습은 없다.

비용 벡터를 사전식 순서로 최소화한다: ① 전체 예정 요청 중 미응답을 포함한 기한 위반 비율, ② 같은 입력 EFT보다 높은 최고 AP의 양의 부분, ③ 같은120초 J−EFT J, ④ 긴급 응답 P95. 단위가 다른 J·°C·ms를 임의 가중합하지 않는다. 이 순서는 **이번 후보의 설계 선택**이지 연구상 합격 기준이 아니다. 평균 가치의 우선순위이며 에피소드마다 기한·열을 지키는 제약식이나 안전 보증은 아니다. AP 계산 불가의 학습 내부 벌점1000은 관측값으로 저장하지 않는다.

| 구분 | 실제 연결 |
| --- | --- |
| 관측 | 도착한 head의 작업·기한 여유·대기 나이, 긴급/일반 큐 길이(각4에서 포화), 남은 공통창15초 bin, lane의 작업·단계, 모형 T−reference·이력H bin |

표본평균을 내는 상태는 압축된 부분 관측이다. 완전한 Markov 상태라고 보장하지 않는다. 방문 횟수가 작은 두 행동의 평균을 사전식으로 비교하는 방식은 오차에 민감하고, 전체 에피소드 비용을 여러 결정에 배분하므로 어떤 대기의 인과효과인지 직접 식별하지 못한다.
