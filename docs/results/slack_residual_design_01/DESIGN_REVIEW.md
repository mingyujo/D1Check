# 재설계 검토 — 학습 없는 prototype 진행 대상으로 제안

2026-10-08 · SLACK-RESIDUAL-DESIGN-01

**구상은 구현할 수 있는 수준으로 구체화했다. 이번 판정은 설계 검토 완료이며 새 정책·배치·학습 실행의 통과 판정이 아니다.** 핵심 가설은 ‘선언된 서비스 기한보다 이른 최초 EFT 예약이 유효한 선택지를 지나치게 제한했다’이다.

확인한 것은 원 기록의 제한 원인이다. 97.9% 요청에 이른 cap이 있었고, cap만으로 탈락한 후보579,528개와 cap 라벨을 제외하면 생기는 추가 즉시 배정6,776 callback을 확인했다. 실제 기한을 다시 검사한 대안 수나 새로운 정책 성능으로 보고하지 않는다. 기존 기록을 설계에 사용한 만큼 그192조건은 새 미열람 시험이 아니다.

## 검증한 범위

직접 읽기 함수7검증, schema107/61의 이름·차원·예산 합, 최대30행동≤32slot, 초기기본확률90% 식, γ1 AP최고증가 보상의 terminal망원합을 확인했다. 기존 실제192원본·완료receipt/binding·실제기한·source23을 대조했다. 환경/학습/기기 추가0이다.

신경망 forward/backward, 새물리기한mask, 예측event rollout, 실제묶음실행, 계산시간, 학습중단/재개는 구현되지 않아 검증하지 않았다. controller 시험 통과라고 기록하지 않는다. [기계 검증 기록](design_verification.json)을 따른다.

## 남은 진행 조건

다음은 새controller와 두 학습 없는 대조를 만들어 gate A/B/C/D를 검증하는 작업이다. 실제 기한·물리실행 차이·전체열/J/응답비악화의 개발 신호가 없거나, 계산비용/시간 계약을 정할 수 없으면 RL을 시작하지 않는다. 현재 비용 모형에서 큰 실제 이득이 가능한지 아직 확인되지 않았으며, 다른 입력의 작은 상한이나 모형오차를 보편적 결론으로 전용하지 않는다.

새 실측·기기실행·모형 fitting·old192 재최종시험·추가학습은 이번 설계에 포함되지 않았다. 설계 숫자는 후속 등록 전 제안이며 새 예산이 아니다.
