## 결론

**추가 실측을 먼저 시작할 이유는 아직 없다. 먼저 공통 기준전력차를 시간 전체로 전용하는 가정을 기존 전력 시계열과 세션 단위 잔차로 분리해야 한다.** 현재 자료는 에너지 상수 offset의 장시간 전용 실패, LOAD_SLOW의 등록부하 AP 예측 개선, 그리고 일반 Arrival/이력 전이의 악화를 함께 보여 준다. 단일 지수감쇠로 offset을 바꾸면 해결된다는 결론도 아직 성립하지 않는다.

기존 자료로 할 분석과 후보 비교를 유한하게 끝내고, 결과가 입력 정보 부족 또는 새 독립 확인 부족에서 막힐 때만 질문이 정해진 통합 실측을 제안한다. 유한창 AP 예측 개선에 물리적 평형/유일 τ 식별을 요구할 필요는 없지만, 미식별 τ로 긴 창/임의 초기이력까지 정확하다고 선언할 수도 없다.

### AP τ와 초기조건

LOAD_SLOW의 저장 profile은 최종τ1920 상단, LOSO1920/1920/1920/960이다. 전체개발 MSE는τ960에서0.0920445,1920에서0.0914721로 작은 차이다. rank6은 국소 수치감도이고 관측창 밖 평형/유일 시간상수 식별의 증명이 아니다. fast 제거 뒤 load/clock shape cosine0.984673도 초기 macro에서 원인 분해가 어려움을 보여준다.

긴 C0가 공통 clock 대조를 악화시키고 긴 LOAD에서 고정 LOAD_SLOW가 잘 맞는 것은 부하연동 표현의 예측 근거다. 그러나 C0→LOAD 한 block이라 날짜/순서/배터리/관측variant가 완전히 분리되지 않는다. 긴 C0 AP도28.2→28.5°C로 바뀐다. 최종 AP가 돌아왔다는 사실로 내부열/주변의 평형이 회복됐다고 선언할 수 없다. 현재 저장된 인접τ 민감도는120초 한 점뿐이므로600초와1920초 회복 지원의 불확실성 근거로 전용할 수 없다.

AP 현재 MAE는 관측 시각별 평균이다. 긴 C0/LOAD 표본881/923처럼 관측밀도가 달라서 시간구간별 해석에는 time-weighted 보조지표도 유용하다. 원 MAE를 바꾸거나 time-weighted 값이 더 유리해서 주지표를 교체하면 안 된다. 센서0.1°C 양자화와 불규칙 조회를 CI/정확도한도로 임의 변환하지 않는다.

## 3. 기존 자료로 먼저 끝낼 정확한 PC 작업

순서를 다음처럼 고정하는 것이 적절하다. 아래는 후속 실행 제안이며 이번 검토에서는 fit/재생 배치를 실행하지 않았다.

1. **분모·시간·입력 고정:** 개발4와 archive29(중복 sustained8 제거), long2, 미시도확인4/부분실패를 각각 명시한다. 계약·APK·초기 AP/preW·prep·관측variant·실제 상태의 지원 맥락을 결과를 보지 않고 적는다. 원자료 hash/원식/기존 후보는 보존한다.
2. **에너지 잔차 분해:** 기존5초창 잔차를 state 점유/등록 유휴 episode/준비/최종유휴로 세션별 표시한다. 같은 세션의 `P_pre` 오차와 state increment 혼합을 구분한다. 평균 signed 잔차, 각 phase 절대J, 5초창 절대오차합, 원식대비 차이·최악세션을 모두 남긴다. 긴2는 개발자료에 넣지 않는다.
3. **기존 AP의 유한창 민감도:** 저장된 각 LOSO/full τ profile의 계수로만, 최적화 없이600초 및 회복covered AP 전체 경로/최고온도/방향을 계산한다. 새τ상한 확대·우승τ 재선택을 하지 않는다. profile 범위는 확률CI가 아닌 이미 적합된 대안의 stress envelope라고 적는다. 120초 근접성을 긴창 식별로 바꾸지 않는다.
4. **원식 대비 새 후보 최대2개만 사후등록·비교:** 개발4만 계수 학습. 세션 전체 LOSO에서 family/τ 선택은 training3 안에서 하고 heldout1 점수로 내부τ를 선택하지 않는다. archive29/long2는 선택 이후 봉인후 재적합없이 사후 기술평가. 같은밤4개 LOSO를 다른날 독립 확인으로 승격하지 않는다.
5. **공동표·종료:** 등록600초에는 동일 창 AP/J, 회복에는 각 센서의 실제 가용범위·coverage를 병기하고 같은 prefix 에너지끼리 비교한다. 과거120초J와 전체AP경로는 별도 legacy 기술층위로 남긴다. 서로 다른 층위를한 평균으로 합치지 않는다. phase/그룹/세션 비악화 여부와 각각 최대 악화를 공개한다.

주요 비교창은 원계약으로 정하며 소수 구간을 사후 찾거나 결과에 맞춘 correction 종료시각을 만들지 않는다. 완전 회복끝의 power 결측0.350/0.578초는 계속null로 두고 covered prefix만 별도로 보인다. long2로 조정하면 그 순간두 block 모두 해당 새모형의 개발자료가되므로 새 독립 확인이라고 부를 수 없다.

### 권고 후보 — 새 구조 최대2개, AP는 동결 유지

**후보1(우선): 공통 offset을 없앤4state-only 에너지.** 동일 `P_pre`/실제lane 상태를 쓰며 idle 공통δ=0을 제약하고4개 비음수 state increment만 개발4에서 추정한다. 현재 기존원식도δ=0이지만 여기서는 긴 macro의4state를 다시 추정한다. 가장 작고 τ 추가가 없으며 유휴에서 상수오차를 강제로 끝까지누적하는 문제를 제거한다. 다만 C0 오차는 그대로이고 baseline 오류가 state 계수에 흡수될 수 있다. 이것은 해결보장안이 아니라 새 느린 항보다 먼저 통과해야 하는 최소 비교다. 세션별 nuisance idle잔차를 진단용으로 분리하되 post-load로 얻은 δ_i를 해당 평가 세션의 예측입력에 넣지 않는다.

**후보2(후보1의 한계가 부하연동 잔차로 남을 때만):4state+부하로 구동되는 유한 전력기억1개.** 예를 들어 `Z'=-Z/τ+u_actual`, `Z(35)=0`, `P=P_pre+state4+aZ`이며 입력은 관측전력 대신 실제lane의 동결 부하proxy다. 추가효과는 무부하에서0, 부하종료 뒤감쇠하므로 상수δ의 무한 누적과 다르다. τ는 기존유한 grid/개발관측길이로 사전에 제한하고 계수/τ는 training3에만선택한다. AP의τ나 새에너지coeff를 반대 head에 강제로 주입하지 않는다. 양/음 session 기준변동까지 이 한memory로 설명된다고 주장하지 않는다. energy-memory30의 관측prefix 잔차 보정과 다른 offline 입력이지만, 여전히 가설이다. rank/제외민감도 또는 무부하/긴idle 악화가 남으면 미채택으로 종료한다.
