# A24 닫힌 비교 묶음 원자료

이 폴더는 기존 등록 행의 공유용 부분 뷰이며 실행계획·독립 반복을 새로 만든 것이 아니다. 정상 완료/시작 거절/미실행과 예정 작업량은 attempts_all.csv 및 각 ZIP의 BLOCK_STATUS.json을 확인한다. 원자료는 원바이트이며 FILE_SHA256.json과 ZIP SHA로 검산했다. 진행 중 원자료는 복사하지 않았다. 모델·APK·승인 이미지·키·개인 경로/기기식별 설정은 제외하고 SHA/제외 사유를 남겼다. J는 미판정이고 AP는 HAL 보고값이며 표면온도는 미검증이다.
