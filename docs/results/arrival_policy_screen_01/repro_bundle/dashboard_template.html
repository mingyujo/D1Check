동결 정책 일정의 응답 결과 + 상태별 가정 전력·AP 사후 회계 · 실기기 정책 검증 아님

δ는 사용자가 조작하는 연구용 값이며 합의된 서비스 기준이 아닙니다. 예정 도착 기준 긴급 1.5초·일반 6초도 연구용 요청별 기한입니다. 모든 정책에 동일한 24요청·실현 벡터·120초 공통창을 적용합니다. 본 표의 정책은 전력·AP 온도를 배정 판단에 사용하지 않습니다.

응답·기한·에너지·AP 비교

긴급 P95는 각 seed의 완료된 긴급 6건 nearest-rank P95입니다. 전체 선택 시 seed별 P95의 산술평균이며 합친 30건의 P95가 아닙니다. 미완료·실패는 위반율의 전체 예정 요청 분모에 남깁니다. 이 보존된 PC 결과에는 미완료·실패가 없습니다. 에너지와 AP는 실측값이 아닌 입력 가정의 사후 계산입니다.

기기 전체 전력·AP 탐색 가정

각 W는 해당 순간 기기 전체의 절대 전력입니다. 유휴 대비 추가 전력이 아니며, 동시 상태에서 단독 전력과 유휴 전력을 더하지 않습니다. 큐 대기는 같은 활성 상태 또는 idle에 포함됩니다. 측정된 CC_DG 고정 묶음은 여기 B2의 CG_DC나 B3의 탐지 CPU＋GPU 계수가 아닙니다. 모든 숫자는 물리적 가능 범위가 확인되지 않은 스트레스 입력입니다.

AP 평형값과 τ는 기존 1차 열모형의 탐색 가정입니다. AP는 BAT·표면 온도가 아니며, 열이 실행시간이나 정책에 피드백되지 않습니다. BAT 모형·절대 에너지 정확도는 미인증입니다. 빈값·잘못된 값은 0으로 보정하지 않고 계산 불가로 표시합니다.

B2−B3 독립 병행 전력 경계

일정 고정 사후 회계의 선형 동률선입니다. 세로축은 B3가 주로 쓰는 탐지 CPU＋GPU의 전체 전력, 가로축은 B2의 분류 GPU＋탐지 CPU의 전체 전력입니다. 나머지 상태 전력은 위 입력값으로 고정합니다. seed 전체에서는 점유시간 평균의 경계이며 모든 seed에서 같은 부호라는 뜻이 아닙니다. 종전 공통 병행 전력 2.070–2.100W는 두 서로 다른 상태를 묶은 가정상의 경계로 기기 임계값이 아닙니다.

근거·지원 범위·재현

응답·점유: CAL-03 개발 기반 시간 모형과 동결 PC 시나리오의 조건부 모형 결과. 같은 135개 선택 일정만 제한 재생해 보존된 응답 지표와 대조했습니다. 이 24요청 도착 경로의 실기기 trace 재생·독립 예측 검증은 없습니다. 전력·AP: 상태별 전용 탐색 가정이며, 기존 실기기 고정 870건 CC_DG는 이 도착 경로를 검증하지 않습니다.

지원: CPU_URGENT, 개발 단계에서 고정된 B2, 축소 PC B3. FIXED_SPLIT·P는 같은 표에서 응답만 보이고, 상태별 통합 비용 일정이 없어 에너지·AP를 계산 불가로 표시합니다. 기존 5정책 요약도 보존됩니다. 병행 API 점유는 GPU kernel 동시 실행 증거가 아닙니다.
