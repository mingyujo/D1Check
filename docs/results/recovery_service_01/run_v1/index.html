냉각→속도 회복 법칙 미확인, AP 후보 미채택. 개발4/이미 본 확인4 부하 세션과 C0 4개를 재사용했다. 같은 개발자료의 고정시간 대조는 기존 동결보다 확인 오차가 줄었지만, AP 입력은 그 대조보다 악화했다. 기본/RL/strict/experiment_ready=false 불변이며 새 실측0이다.
