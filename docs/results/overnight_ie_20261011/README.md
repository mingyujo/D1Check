## 판단

최종 판단은 `confirmation_verdict.json`의 전 조건 비악화 기준이다. 기한 위반 또는 일부 조건의 AP/J 증가를 평균 비용 감소로 상쇄하지 않는다. 정책별 행동과 반례는 `behavior.json` 및 전량 CSV에 남겼다.

R1/R2가 기존 Band와 동일 일정이면 그 trace에서 별개 스케줄러 우위 실측은 성립하지 않는다. 대표96trace의 Band/R1/R2/L0는 동일 일정이며, 기존 Rule만 짧은 냉각 대기에 따른 작은 모델 비용 차이를 보였다. 대표trace는 결과 후 바꾸지 않았다.

냉각으로 서비스시간이 회복되는 효과는 고정5phase에 없다. AP는 모형 온도이고 에너지는 원 실측계수 기반 추정이다. 제어 계산시간은 PC에서 기록했으며 휴대폰 오버헤드/에너지로 전용하지 않는다. 작은 AP/J 차이와 독립 실제 정책 개선의 증거를 구분한다.
