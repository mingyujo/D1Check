## 사전 고정한 최소 후보와 대조

기존모형은상태입력 `u_old = slope(state)-slope(idle)`의비율을고정하고전체k/g만바꾼다. 기존β=0.0459325203/s·τ=30s·부하전R/H초기화를유지하며,후보는다음과같다.

```
T' = -β (T - R_pre) + Σ a_state I_state + H
H' = -H / 30 + g × u_old / 30
```

추정하는값은비음수상태가열입력4개+기존비율지연항g1개다. R_pre는주변온도아니며H는직접측정한내부온도가아니다. 기존β/τ를유지한것은구조분해를위한고정조건이며새냉각률/τ를식별했다고하지않는다.

| 이름 | 역할/추정값 |
|---|---|
| FROZEN | 기존동결본·fit 없음 |
| RATIO_REFIT | 고정상태비율/고정β/τ에서k,g만다시fit·대조 |
| STATE_DIRECT | 상태가열4개·g=0·원인분해대조 |
| STATE_DELAYED | **사전고정주후보**·상태가열4개+g1개 |

대조중가장잘맞는것으로주후보를바꾸지않았다. 후보4회LOSO+전체4최종fit=5,대조8fit=총13회;비음수최소제곱의32active-face계산은같은추정기의제약해결이며32후보탐색이아니다. β범위확대·τ탐색·새정밀도/전력/스로틀가정0. 같은샘플러라도장구간반복기록/host listing주기/체류길이는기존Arrival와다르며,전이악화를그중어느하나의비용으로단정하거나임의보정하지않는다.
