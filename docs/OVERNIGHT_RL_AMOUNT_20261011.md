# 같은 learner의 PPO 학습량 비교

**같은 learner를 세 seed 모두512에피소드까지 연장했지만, 새 확인48조건에서 Band 대비 추가 우위를 확인하지 못했다.** 학습량에 따라 실제 선택이 바뀌었고, 성적은 단조롭게 좋아지지 않았다. 원32→64→128→256→512의 코드·설정·Adam·RNG·보상·상태 schema는 유지했다.

작업 ID `OVERNIGHT-RL-AMOUNT-09`. 2026-10-11 사용자가 오전 회의 준비를 위해 추가 실측·정책 발전·강화학습 연장을 자율 승인했다. 이 절은 그중 CPU/GPU PC 학습량 비교를 담당하며, 실기기 실행이나 새로운 정책 개발과 분리한다. 결과 전에 계약·입력·분석 기준을 고정했다.

## 고정한 비교

- 기존 세 learner(seed 11·23·37)의 최종32 actor·critic·Adam·RNG·승수·커서를 그대로 복원한다. 원 checkpoint는 덮어쓰지 않는다.
- 동일 learner를 누적64→128→256→512에피소드까지 연장한다. 새로운 알고리즘·상태 schema·행동·보상·하이퍼파라미터·학습 seed 교체는 0회다.
- 추가480개 학습 trace는 신규120도착 seed×4부하군이며 문맥은 기존 방식대로 순환한다. 세 learner가 같은 순서를 사용한다. 원32와 새480은 단일 미리 고정한 중첩 학습 순서로 기록한다. 원32 trace를 반복 재생한 것과는 구분한다.
- 각 중간 checkpoint를 이미 관측한 개발24조건에서 모두 평가한다. 유리한 seed 또는 checkpoint를 골라 최종 평가하지 않는다.
- 최종은 신규4도착 seed×4부하군×3고정 비용 문맥=48조건이며, L0·Band 대응·Triton 대응·같은 후보 비학습 Rule·terminal512 세 learner를 모두 평가한다. 학습·개발·확인 도착 seed는 분리한다.
- terminal512 세 learner의 대기 제거 평가를 같은 확인48조건에 추가한다. 유망 seed가 있을 때만 명시 열특징 제거 평가를 추가한다. 비용 예측과 후보 선별까지 열을 제거한 실험이라고 해석하지 않는다.

## 방법론과 판정 경계

현재 자체 masked PPO는 56차원 공개 상태·최대8개 후보×28차원 특징·6출력 critic을 사용한다. L0는 과업별 head의 기한을 비교하고 현재 합법적인 자원 중 예상 응답 완료가 빠른 것을 고른다. 원공동롤링 window4·mean 선별8에서 실제 단건/동시쌍/자원 대기/최대0.25초냉각 후보를 만든다. 비학습 Rule과 PPO는 같은 상태·후보·물리 mask·예측 기반 허용 조건을 공유한다. Band는 평가 기준이며 학습 참조·복귀·예측 후속은 L0다.

PPO는 후보 슬롯을 선택한다. 실제 CPU/GPU 할당·시작·짧은 대기가 행동이며 실행 중 이동·선점·주파수·전력 제한·NPU 행동은 없다. 과거 도착 이력과 공개 lane phase, 실제 AVAILABLE에서 관측한 서비스 추정, 모델 AP/H/slow 추정만 사용한다. 미래 도착과 실제 잔여 실행시간은 정책 관측에 포함하지 않는다.

원PPO objective·AP 주보상·signed J·positive 서비스 비용·승수 갱신·gamma1·8episode update·4epoch·lr0.0003·clip0.2를 유지한다. γ=1이고 실제 경과시간과 유휴 비용은 공통 J/AP 계산에 들어간다. 응답은 분류 OUTPUT_READY/탐지 PERSISTED, lane 반환은 실제 AVAILABLE이며 서로 혼동하지 않는다. 모든 요청에 완료 요구가 남는다.

최종 판정은 원 zero-epsilon 전조건 서비스/J/AP 비악화, low/sustained 절대 기한 조건, 같은 주부하군에서 AP 또는J 한 축 이상의 개선을 유지한다. RL에는 같은 후보 Rule 대비 전조건 비악화도 요구한다. 조건별 Pareto와 부하별 차이는 별도 해석이며 원채택 기준을 완화하지 않는다. 보상 증가와 학습 횟수 증가를 성능 개선으로 대체하지 않는다.

AP는 측정으로 보정한 내부 모형 채널이다. 최고 표면 온도·안전 한도 초과 시간·실기기 판단 에너지는 이번 자료로 계산 불가다. 기존 frozen thermal-only v3 head를 온라인 후보 예측과 최종 AP에 동일 적용하며, 원5phase 서비스와 원J 계수는 유지한다. 냉각에 따른 처리속도 회복은 모델에 없다. 작은 모형 AP/J 차이를 휴대폰의 확실한 절감으로 주장하지 않는다. 확인4도착 seed의 기술적 cluster bootstrap은 세 비용 문맥을 독립12반복처럼 세지 않는다. 물리 신뢰구간 또는 수렴 완료 판정으로 전용하지 않는다.
