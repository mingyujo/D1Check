# 평가 방법

기기별로 같은 요청·납기·모형·관측 구간을 모든 정책에 적용했습니다. 분류는 긴급 요청(기한 0.8초), 탐지는 일반 요청(2초)이며, 실행 중인 추론을 중단하지 않는 비선점 방식입니다. 응답 생성과 자원 반환 시점은 구분합니다.

## 지표

| 지표 | 계산 방법 |
|---|---|
| 정시율 | 기한 내 응답 수 / 전체 도착 요청 수 |
| 응답시간 | 응답 시각 − 계획 도착 시각 |
| P95 | 입력별 nearest-rank P95를 계산한 뒤 산술평균 |
| 예측 소비 | 관측 구간의 모형 전력 적분. A24 J*, S26 API-J |
| 평균 AP | 요청 공급 시작부터 관측 종료까지 AP 온도의 시간 평균 |

미응답·미완료 요청도 정시율 분모에 포함합니다. 소비는 0초부터 관측 종료까지 계산합니다. 요청 공급은 35초에 시작하고 N/도착률 동안 이어집니다. 공급 종료 후 45초까지 배정하고, 60초에 검열을 진단하며, 90초에 관측을 끝냅니다.

## 기기별 설정

| 항목 | A24 | S26 |
|---|---|---|
| 분류 경로 | CPU·GPU | CPU·GPU·NPU |
| 탐지 경로 | CPU·GPU 전이 가정 | CPU |
| 주 입력 | 512건·8건 묶음·명목 25% | 1,024건·16건 묶음·명목 85% |
| 기준선 배정 | 예측 응답에 따른 CPU/GPU 동적 배정 | 분류 GPU→NPU→CPU, 탐지 CPU |
| 표에 제시한 정책 | 안전여유 보완 교사규칙 | BC·서비스 보완 정책 |

명목 부하는 입력 생성 기준이며 CPU 사용률이 아닙니다. 기기 간 절대 성능을 비교하지 않고, 각 기기 안에서 기준선 대비 변화를 봅니다.

## 적용 범위와 상충관계

소비는 실측 자료로 구성한 전력모형의 예측값이며, 실기기 배터리 절감량은 검증하지 않았습니다. 가상 CPU 추론 슬롯 3개, 일부 미측정 경로·병행 간섭은 연구 가정입니다. 정책의 예측·신경망·제어 계산비용도 포함하지 않았습니다. AP 센서 온도는 피부·부품 접합 온도와 다릅니다.

A24 주 조건의 보완 교사는 전체 정시율 100%였으나 명목 50%에서는 726/1,024건(70.8984%)이 정시였습니다. 일반 P95는 주 조건에서도 EDF보다 약 0.055초 길었습니다. S26 주 조건의 긴급 P95는 0.634초로 EDF의 0.340초보다 길었습니다. 확장 32입력 중 명목 105%·32건 묶음·분류 75%인 4입력에서는 EDF보다 소비·온도가 높고 긴급 정시율이 낮았습니다. 해당 비교군과 악화 조건을 자료에 포함했습니다.

온도 모형의 A24 약 0.11℃·S26 약 0.42℃ 평균 오차는 같은 측정 pool의 그룹 분리 개발 평가입니다. 후속 보정값을 앞선 정책 실험에 소급 적용하지 않았으며, 독립 기기 검증이나 정책 순절감의 증거로 사용하지 않습니다. 원시 기록의 물리 검증 실패·미확인 표시는 그대로 유지했습니다.

입력 민감도는 저장된 부하·작업 구성 범위의 분석입니다. 전력·열 계수 민감도와 새 독립 실측은 포함하지 않습니다. S26의 앞선 PPO·교사 초기화 계보와 후속 BC·서비스 보완은 별도 단계이며, 정책 전체 개선을 BC 하나의 효과로 해석하지 않습니다.
