## 오차: 사후 진단, PASS 기준 없음

기존 동결 모형의 확인 공통480초 최종 J 오차는 병행 **−8.468 J**, 직렬 **+32.306 J**(예측−관측)이고 병행−직렬 차이는 예측 **−36.216 J**, 관측 **+4.559 J**로 방향이 다르다. 확인 1세션/조건이므로 이 수치가 오차 보장·모집단 분포가 아니다. 개발 W를 확인 **실제 점유 일정**에 대입해도 최종 J 오차는 병행 **−4.911 J**, 직렬 **+29.417 J**여서 순위 문제를 해결하지 못한다. 이를 새 독립 예측이라고 하지 않는다.

새 시간축 진단에서 누적 J 경로 MAE/최대절대오차는 병행 **19.366/53.151 J**, 직렬 **16.866/32.355 J**다. AP 공통창 경로 MAE/최대절대오차는 병행 **0.425/1.8°C**, 직렬 **0.245/1.0°C**. 연구용 **30°C** 초과시간(공식 안전 한도 아님)의 비교 가능 표본 1초 격자에서 병행은 **−75초/479초**, 직렬 **−2초/480초** 오차다. 병행의 1초 phase 전환 gap은 관측/모형 동시 유효 범위에서 빠졌으므로 480초 전체 초과시간 결과는 미지원이다. 기존 AP 평가 전체 준비~냉각 경로와 새 공통창 경로는 분모가 다르다. 센서 1초 보간은 측정 해상도를 높이지 않으며 표본을 독립 반복으로 세지 않는다.

**판정:** 구현·적분·지원 차단은 PC에서 확인했으나 고정 episode의 공통창 에너지 차이 방향 실패, 부분 AP 초과시간 경계, 조건당 확인 1세션으로 정책 선택에 충분한 모형이 아니다. 확인 오차로 계수나 구조를 다시 선택하지 않았다. AP 최고 방향이 맞더라도 다른 도착·초기 열상태·장시간 반복을 예측한다고 해석하지 않는다.
