# 데스크톱에서 필요한 자료

노트북의 PC 준비에 필요한 승인 모델2개·labels2개·anchors·canonical PNG1개·tensor SHA2개는 확보됐다. 실행기/검산/APK 준비를 위해 데스크톱의 대규모 학습 폴더나 RL 가중치를 옮길 필요는 없다. 기존 GEN002·CAUSAL·NODGPU 작업을 중지하거나 재실행하지 않는다.

**10월15일 `ec8a1424`의 기존 GEN002 동결 소스·프로필은 인수·SHA 검산 완료했다.** [인수 기록](DESKTOP_REFERENCE_INTAKE.md)과 [분석 초안](ANALYSIS_CONTRACT_DRAFT.md)을 마련했다. 새 8군 수치 예측과 최종 분석 계약은 제공되지 않았으며, 이를 노트북에서 CONFIRM 전에 작성·동결할 수 있다는 사용자 지시를 기록한다. 진행 중 결과를 FINAL로 바꾸지 않는다.

| 자료 | 필요한 내용 | 아직 없는 경우 |
| --- | --- | --- |
| 기존 동결 참고 모형 | GEN002 소스59개·프로필8개 인수 완료; 새 strict8군·고정 WAIT·readback·초기 상태 대응 adapter는 미작성 | 기존 모형을 그대로 새 예측으로 사용하지 않음 |
| 동일8군 사전 예측 | L64 BASE/PAIR_G, C252 CPU/GPU, M128 BASE/ORDER/PAIR_G/WAIT200; 이번 exact bank SHA·입력·기한·120/180/210창과 함께 요청별 일정/KPI 및 처치−기준 Δ | 새 PC 예측 작업으로 별도 등록; 실측값을 보고 맞추지 않음 |
| 분석 계약 | J0/120/180·AP35/180·전체 분모·실패/pending/drain·다섯 대응 비교의 미동결 초안 작성 완료; 실제 센서/시각/적분/오차 기준과 분석 코드 필요 | `frozen=false`; CONFIRM 거부 |
| 완결 결과의 계보 | 어떤 자료가 보정/선정/독립 평가에 쓰였는지, 이미 본 확인 자료, source commit 및 변경 여부 | 독립 검증으로 주장하지 않음 |

완료된 모형이 WAIT·새 병행/도착/준비 상태를 지원하지 않으면 null/미지원으로 남긴다. 다른 기기 값·미측정0·결과에 맞춘 계수를 넣지 않는다. 현재 bank의 M128 간격은 원 `5682082a…872db2` 모형의 명목 AVAILABLE 평균에 근거하며, 이것만으로 최신 열·에너지 예측 완료를 뜻하지 않는다.

이 요청은 노트북 PC 준비를 막지 않는다. 사전 예측과 분석·계측·초기 gate를 고정하기 전 CONFIRM40을 시작하지 않는 것이 경계다. 기기 identity·AP 센서·기기 품질/위임·초기 gate는 데스크톱에서 대신 확인할 수 없으며 나중의 A24 I4/F4에서 확인한다.

지금 추가로 옮길 RL 가중치나 대규모 학습 폴더는 없다. 데스크톱에서 향후 새 모형/예측을 완성하면 exact commit·파일 SHA·bank SHA·자료 계보를 전달한다. EP813/EP814 상태는 사용자 인계이며 자동 재시작·재수집을 하지 않는다.
