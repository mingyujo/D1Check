# A24 노트북에 전달하는 데스크톱 기존 자료와 미작성 범위

2026-10-14. 이 폴더는 기존 동결 바이트의 참고 인계다. 이번 A24 8군의 CONFIRM 모형·예측·분석이 동결됐다는 뜻이 아니다.

## 요청한 세 가지의 실제 상태

| 자료 | 상태 |
| --- | --- |
| 기존 동결 시뮬레이터 소스·물리 프로필 | GEN002 59개 소스와 8개 프로필을 원 바이트 그대로 제공. A24는 그중 4개 프로필 |
| 이번 8군의 사전 수치 예측 | **없음.** J180·평균AP·납기·정책차 예측표와 이를 봉인한 파일/커밋이 없음 |
| 이번 실측의 분석 계약 | 상위 PLAN.md에 제안은 있음. 샘플링/허용gap/오차 허용치/정확한 구간 방법·실행 분석코드까지 갖춘 최종 동결 계약은 **없음** |

이번 실측용 최종 예측 모형/adapter와 최종 선정 PPO도 아직 없다. 기존 256/1024 checkpoint를 임의로 최신 확정 정책으로 선택하지 않는다. 최신 동결 소스와 최종 선정·독립 확인 완료는 구분한다.

## 파일과 SHA

- [AVAILABILITY.json](AVAILABILITY.json): 8군과 미작성/미동결 항목의 기계 판독 상태.
- [GEN002.json](GEN002.json): 기존 등록 원본. SHA256 `b3156ad8f300e85064f3cfdeb02b3c4a414c0b895e2d88465d6a6f1779e95327`.
- [SOURCE_PROVENANCE.json](SOURCE_PROVENANCE.json): 원본 상대 경로→복사 경로→SHA 대응. 원 체크아웃 HEAD만으로 당시 미커밋 소스를 식별할 수 없어 원 등록 SHA와 파일 SHA를 함께 쓴다.
- [FILES_SHA256.json](FILES_SHA256.json): 이 폴더의 파일 바이트 SHA256 및 Git blob SHA1. 이 파일 자체는 순환 참조 때문에 목록에서 제외한다. 실제 업로드 commit은 인계 메시지/PR의 정확한 commit 링크를 따른다.
- [ANALYSIS_CONTRACT_STATUS.json](ANALYSIS_CONTRACT_STATUS.json): 기존 제안과 아직 동결하지 않은 값/코드의 구분.
- [기존 A24 64세션 계획](../PLAN.md): 8군×DEV2/CONFIRM5, 별도 I4/F4. 기존 문서는 변경하지 않았다.

A24 계획에 사용한 프로필은 [A24_G36_M1_coupled.json](model/vendor/profiles/A24_G36_M1_coupled.json), SHA256 `ee36899cc7c5ea17a689bbd746e8906866e846ceb0e68685d8faa17b20009df3`다. M0 및 thermal_strong 두 조건도 함께 보존하며 유리한 결과로 한 층을 사후 선택하지 않는다. M1/강한열 조건은 가정·민감도 범위를 포함하고 실제폰 효과가 검증된 프로필이 아니다.

## 그대로 8군 예측으로 사용할 수 없는 차이

`model/code/plant.py`는 기존 V2 학습용 관측·제어 경로다. 다음을 새 실측 계약에 연결한 adapter/새 등록은 아직 없다.

1. 기존 WAIT는 도착·상태 사건에 중단될 수 있다. 이번 고정 WAIT200은 새 도착으로 타이머를 취소/연장하지 않는다.
2. 기존 controller를 새 strict FIFO/EDD·전역직렬·PAIR 처방과 같은 정책이라고 재명명하지 않는다. 같은 원점의 실제 순서/배정/겹침/dose를 검산할 adapter가 필요하다.
3. 기존 비용 경로는 미완료일 때 180초 비용/열을 null로 내는 경우가 있다. 이번 실측의 관측 소비와 미완료·서비스 손해를 보존하는 계약으로 구분해야 한다.
4. 기존 5단계의 persist 완료와 새 일반 응답 readback 성공은 같은 경계가 아니다. readback 비용·해제 의미와 APK·입력·runtime·초기 상태를 연결해야 한다.

따라서 단순 평균 산술·과거 다른 workload 결과를 이번 8군의 사전 수치 예측으로 채우지 않는다. 현재 자료에서 새 예측/fit/시뮬레이션은 실행하지 않았다. 학습 orchestrator/watch/reproduce를 노트북의 실측 명령으로 실행하지 않는다.

## 노트북 측에 전달할 내용

데스크톱에는 기존 GEN002 소스·프로필만 있고 이번 8군 수치 예측과 최종 분석 계약은 없다. 없음을 유지해도 된다. 필요하면 이 참고 자료에서 별도 버전으로 adapter·분석 코드·사전 예측을 만들고 파일/commit/SHA를 묶어 CONFIRM 자료를 보기 전에 동결한다. 실제 기기 계측/초기 상태가 없으면 임의 값을 실측값으로 채우지 않는다. 새 가정·기존 자료·기기 검증을 구분한다. 기존 데스크톱 V2/CAUSAL/NODGPU 동결 실험·원장은 변경하지 않는다.

APK·AI 모델 binary·입력 이미지/tensor·private raw·기기 식별자·키는 이 폴더에 없다. NumPy/Torch 등의 원 환경과 노트북 새 분석용 dependency lock도 구분해야 하며 이 인계가 휴대폰 실행 준비 완료를 뜻하지 않는다.
