# 최초26.1℃ 기준 개발 묶음 W1 — 종료

최대2시도/동일 분류252건씩을 사전 고정했다. 첫 순서는 seed2026101508로 GPU→CPU였다. 준비 후 최초 안정60초 이력 중앙값26.1℃를 GPU 본요청 전에 고정하고 CPU도 같은 기준±0.5℃·기울기0.1℃/분·최대10초gap·최대600초 대기를 적용했다.

GPU는252/252건 기한 내 완료·출력252검산 통과,긴급 P95=271.841ms였다. 시작 직전AP26.1℃,준비 후60초26.1~26.2℃. AP평가창35~180초의 평균27.2648℃·관측최고27.8℃다. 에너지J는 계산불가다.

CPU는본요청0으로 사전 거절됐다. 준비 후 AP234회 읽기27.1~28.7℃·마지막27.7℃로 허용 범위25.6~26.6℃ 안인 읽기0회였다. 워밍업8회와 예정252건 UNFINISHED를 보존했다. DRAINED/저널 close 후 빈 소유프로세스만 종료했다. CPU 성능 실패나 기기 고장을 뜻하지 않으며 대응 성능 비교는 보류다.

원64 중28시도는 보존하고 미시도36 중2만 이 묶음에 배정했다. 실패를 정상으로 교체하거나 구 결과를 새 반복에 합산하지 않는다. 이후 사용자의 추가 대기는 앱 없이 수행했고, 대기 중 CPU 후속은 GPU 우선 지시로 앱/START0에서 취소했다. 새 현재값 묶음은 별도다.
