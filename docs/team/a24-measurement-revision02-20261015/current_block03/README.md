# 현재 온도 기준 새 GPU→CPU 개발 묶음

사용자가 현재 값 기준으로 GPU부터 다시 수행하도록 명시했다. 당시 수동 냉각 관측의 마지막 고정66초 이력에서 최초 안정60초 중앙값 **27.6℃**를 새 GPU 본요청 전에 봉인했다. 기존26.1℃ GPU 결과/CPU사전거절을 보존하고 합산하지 않는다. 대기 중 CPU 후속은 새 앱·워밍업·START0에서 취소했다.

새 기준은 수동 대기 상태에서 정한 개정 v3다. 원 준비 후 첫 기준 방식과 구분한다. GPU→CPU 순서와 기준 선택은 새 결과 확인 전에 고정했다. 두 군은 같은27.6±0.5℃·60초 이력·기울기0.1℃/분·10초gap·준비 후 최대600초를 적용한다. 군별 재기준은 없다.

동일 모델/승인 이미지/도착/기한/분류252건,4runtime상주/각2회 공통 준비를 유지한다. 군간 임의 추가 유휴0초이며 각 군의 실제 준비 후gate를 거친다. 선점·주파수·기기 설정 변경은 없다.

최대2시도/504예정요청. 원64 중 이전30시도 보존,새2는 미사용34에서 배정한다. 미시도·거절도 분모에서 없애지 않는다. 사용자 시간 연장으로 상한13:20 KST,새 앱은21분·START는5분 여유가 있어야 한다. 이전12:50 window는 보존하고 [연장 계약](EXECUTION_CONTRACT_EXTENDED.json)의SHA에 승인했다. manifest 바이트는 변하지 않았다.

개발 n=1이며 내부 잔열·주변·외부부하까지 동일하다는 뜻은 아니다. HAL AP를 표면온도/에너지로 해석하지 않는다. J계산불가·수치예측정확도미검증·experiment_ready=false다.
