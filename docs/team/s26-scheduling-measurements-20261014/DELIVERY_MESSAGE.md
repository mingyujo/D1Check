S26 추가 실측 요청을 한 문서로 정리했습니다. 우선 항목별 가능 여부, 필요한 실행기 보완, 예상 일정을 확인 부탁드립니다.

전체 요청·우선순위: https://github.com/mingyujo/D1Check/tree/codex/s26-measurement-request-20261014/docs/team/s26-scheduling-measurements-20261014

우선순위는 다음과 같습니다.
1. P0: 실행기/계측 확인과 기존 전력 오차 재현
2. P1: 분류 CPU/GPU/NPU 배정·순서·병행·짧은 대기
3. P2: 같은 작업량의 버스트/균등 도착, 최근 CPU 부하·열 이력, 긴 대기
4. P3: 열 회복·경로 전환·상주/재초기화 비용, 부하/기한·정책 조합
5. P4: 탐지GPU 등 새 경로와 CPU스레드 설정

세션 수를 정한 부분은 기존 핵심87+보완56+전력오차 재현16=159세션 제안입니다. P3/P4는 지원 확인 후 별도 산정하며159에 포함하지 않았습니다. 가능/보완 필요/미지원과 항목별 소요시간을 회신 부탁드립니다.

같은 요청에서 한 요소씩 바꾸고 에너지·AP온도·납기와 실제 순서/겹침/대기량을 함께 확인하려 합니다. 채택한 보완군은 기존 기준군과 같은 블록에 배치합니다. 기존 M6의600요청 시간 자료를 다시 수집할 필요는 없습니다.

현재는 설계·기능 확인 요청이며, 새 실행기·입력·계측·예산을 동결하기 전에 임의로 측정을 시작하거나 미지원 처방을 대체하지 않도록 부탁드립니다.
