# 에너지·AP 오차 개선 목표 복구와 실제 후보 평가

**목표는 에너지와 열(AP) 오차를 모두 줄이는 것이다. 직전 AP-only 범위 정리를 전체 정확도 개선의 대체물로 쓰지 않는다.** 이번에는 빠졌던 에너지 후보를 실제 구현·추정·평가하고, 고정 AP 후보와 세션별 결과를 함께 정리했다. 추가 실측은 없다.

결론: **이번 두 장시간 조건의 등록600초에서는 양쪽 출력의 개선 근거가 있지만, 긴 유휴와 과거 조건의 악화 때문에 전체 시뮬레이터를 교체할 후보는 아직 확보하지 못했다.**

## 후보와 자료 역할

- 기존에 구현된 에너지 식 한 개만 사용했다: `E(t)=P_pre*t + δ_idle*max(0,t−35) + Σ ΔP_state*실제점유시간`. 기기 전체 에너지이며 유휴와 추가 전력을 중복 합산하지 않는다.
- 개발4의5초 적분 구간과 실제 점유율로 부호 있는 기준전력 보정1개＋비음수 상태 계수4개를 추정했다. 온도·주변·스로틀·주파수 계수를 만들지 않았다. 4세션 제외평가＋전체4의최종추정=정식fit5회, 후보 구조1개다. 센서 표본은 독립 세션이 아니다.
- 최종 δ_idle=+0.0241496W. 추가전력: 분류CPU0.770509 / 탐지CPU0.695872 / 분류GPU0.373651 / 분류GPU＋탐지CPU1.075216W. 이는 해당 프로토콜의 유효 계수이며 자원 자체의 인과적 소비전력 인증이 아니다.
- 에너지 새 후보의 학습에는개발4만 썼다. C0/LOAD 결과를이미본뒤후보구조를정했으므로새에너지평가는 **학습에미사용한자료의사후평가**다. 새로운blind독립확인이아니다. [실행 전 등록](results/energy_ap_joint_followup_01/registration.json)·[동결 receipt](results/energy_ap_joint_followup_01/run_v1/fit_receipt.json).
- AP는이미동결한LOAD_SLOW를그대로사용했다. 이번AP fit0, 계수교체0. 새에너지계수를기존AP식의전력proxy에넣지않았다. 임의결합으로앞선AP확인결과를바꾸지않는다. [분리된두출력bundle](results/energy_ap_joint_followup_01/run_v1/combined_bundle.json)은새물리적열결합/열→처리시간모형이아니다.

## 이번 실측의 원래 고정600초 창

에너지는 `[35,635]` 전체600초를적분하고, AP MAE는같은창에확보된원관측시각에서비교한다. 이창은실측전에고정된것으로결과를보고고르지않았다.

| 조건 | 기존 J차이(예측−관측) | 에너지후보 J차이 | 기존 AP MAE | 고정 AP후보 MAE |
|---|---:|---:|---:|---:|
| C0 | −13.1476J | +1.3421J | 0.0130°C | 0.0130°C |
| LOAD_A | −15.1508J | +10.7634J | 0.5437°C | 0.1862°C |

C0/LOAD 600초 에너지 평균절대오차14.1492→6.0528J. 참고 `[0,120]`의두조건평균절대오차6.3253→1.1829J이며두시간창을같은지표로합치지않는다. AP 공통＋회복 경로는 이전 확인처럼 C0 0.0908°C, LOAD 원식0.4371→LOAD_SLOW0.1728°C다.

## 긴 유휴 악화: 완료로 숨기지 않는 핵심 문제

| 실제 관측이 덮인 등록 회복 구간 | 기존 J차이 | 새 J차이 |
|---|---:|---:|
| C0 `[635,2554.8066]` | −23.1515J | +23.2110J |
| LOAD `[635,2554.5103]` | −7.6549J | +38.7005J |

원래전체회복의끝0.350/0.578초는센서가덮지않아 **전체회복J/오차는null**이다. 위표는실제로덮인동일prefix의비교이며전체로표현하지않는다. 작업종료뒤전체유휴prefix `[545.1858,2554.5103]`에서도 LOAD 절대오차10.998→37.526J로악화했다.

수학적원인은명확하다. 부하종료뒤에상태추가전력은0이지만δ_idle은끝까지적용되므로 LOAD 유휴2009.324초에 `0.0241496×2009.324=48.5243J`가추가됐다. 기존−10.9984J를+37.5259J로바꾼산술이다. **공통창에서추정한기준전력차가긴회복에서도일정하다는가정은이자료에서부적합하다.** 실제기기의원인은주변·OS·관측부하·잔열등으로이자료만으로확정하지않는다. 결과를보고보정종료시각을임의로잘라오차를줄이지않았다.

## 전체 기존 자료의 결과

등록공통＋회복을합친실제관측prefix `[35,센서끝]`에서는 C0 차이−36.299→+24.553J, LOAD−22.806→+49.464J다. LOAD 전체경로가악화하므로600초개선을전체실측에너지오차개선으로표현하지않는다.

| 평가 층위 / J창 | 세션 수 | 원식 평균절대J | 후보 평균절대J | J악화 |
|---|---:|---:|---:|---:|
| 개발 세션 제외 / 참고120초 | 4 | 12.6970 | 7.5357 | 1 |
| 개발 세션 제외 / 등록600초 | 4 | 40.7951 | 39.0751 | 1 |
| 이미 본 과거 사후 / 참고120초 | 29 | 5.5222 | 5.4023 | 14 |
| 이미 본 긴 조건 사후 / 참고120초 | 2 | 6.3253 | 1.1829 | 0 |

과거29의평균만보면조금낮아지지만14세션의에너지가악화했다. AP도이전13세션악화를그대로보존했다. 참고120초J와기존전체AP경로가둘다비악화인것은개발3/4·과거8/29·새긴2/2이며 **정책효과/정확도PASS가아니다**. 서로다른시간창/평가층위를한전체평균으로섞지않는다. [전체J/부분창표](results/energy_ap_joint_followup_01/run_v1/energy_errors.csv)·[AP와함께보는세션표](results/energy_ap_joint_followup_01/run_v1/joint_errors.csv).

원자료단위·적분·실제worker/lane 경계는앞선검증을재사용했다. 이번에확인한것은새에너지식의기간전용한계이며시간축을옮기거나원자료를수정한것이아니다. A24 raw=mA 해석과절대J미인증도유지한다. 에너지값을SOC/사용시간/BAT 온도검증으로확대하지않는다.

## 구현·검증·재현

[새 PC 분석 구현](../tools/d1_energy_ap_joint_followup.py)은 fit/evaluate를분리한다. 추정후candidate byte hash를확인하며evaluate는재추정하지않는다. 원시관측전력·부하후AP는예측입력에넣지않고 pre-load W와실제상태/시간만쓴다. A조건부비용평가이며예정도착부터의종단간B/새정책배치/RL 학습은0이다.

```powershell
python -B -m unittest tools.test_d1_energy_ap_joint_followup -v
# 새 출력폴더에서만 추정. 기존 run_v1은 그대로 둔다.
python -B -m tools.d1_energy_ap_joint_followup --action fit --output output/energy_AP_reproduce
python -B -m tools.d1_energy_ap_joint_followup --action evaluate --output output/energy_AP_reproduce
python -B docs/results/energy_ap_joint_followup_01/plot_results.py
```

마지막plot명령은저장된run_v1값의그림만재생성한다. NumPy/Matplotlib 및Korean font가필요하다. [확인 화면](results/energy_ap_joint_followup_01/index.html).

- 관련검증7건통과: 실제constrained fit의합성계수복원,전체전력/구간가산성,35초경계,긴유휴의offset 누적,대상관측비사용,개발/확인분리,결측endpoint/null,비양수/미지원상태/시간상한차단.
- 원식5682082a…·AP후보aa28410d…·등록source7hash 불변. [검증](results/energy_ap_joint_followup_01/verification.json). 실기기/ADB/설치/추론/실측/설정/새기기계획/claim0,기존RL/다른작업보존.

**원래 목표는 아직 전체범위에서 완료되지 않았다.** AP와에너지에각각실제개선이있지만이번상수전력보정후보는긴유휴/과거악화로기본채택하지않는다. 다음수정대상은추가실측준비가아닌 **기준전력차를부하이후에도상수로유지하는가정**이다. 기존전류시계열에서그시간의존성을다룰수있는지먼저확인해야하며,이번후보를성공할때까지자동재조정하거나새수집을만들지않는다.
