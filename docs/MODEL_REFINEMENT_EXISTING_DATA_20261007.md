## 사전에 고정한 후보와 식별 한계

기존 AP는 `T′=−β(T−R)+k·u+H`, `H′=−H/30`이며 준비AP로 유효유휴R와 초기H를 함께 추정한다. β=0.0459325203/s, k=1.0757035775, 작업에 의한 추가잔열g=0. u는 기존 상태별 열 입력에서 유휴항을 뺀 값이다. R는 주변온도가 아니며 H는 실측 내부온도가 아니다.

세션 동일가중 적합. 단순AP1열/지연AP2열 수치rank 충족, 전력추세 비영정보가 있지만 실용적·물리적 식별 인증은 아니다. 개발제외 시g=0.280~0.762, α=0.953~3.184로 변동했다. 개발3의 정책·순서·초기열 교란 때문에 온도×상태 전력계수나 새 열시간상수를 추가하지 않았다. 실제 점유율은 기존 노출시간으로 사용한다. 미관측 주변온도·숨은 상태값을 만들지 않는다.

후보선택은 개발 한 세션 전체를 제외하는3fold. 각 제외세션에서 해당 출력이 동결본보다 악화하지 않는 후보 중 평균 최소를 고정했으며 AP/에너지 모두 FROZEN이 남았다. 정확도 허용폭/PASS 기준이 아니라 후보 유지 규칙이다. 기준모형은 원개발3을 이미 사용했으므로 이 LOSO 대조 자체를 기준모형의 독립검증으로 해석하지 않는다. 확인 결과로 후보를 더 추가하거나 선택기준을 고치지 않았다.
