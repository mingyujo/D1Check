## 4. 판정 (등록에 그대로)

- 가드 먼저: 128건 (A24 48건) 전량 완료 · 기한 충족 수가 비교군 이상. 가드를 못 지키면 열·에너지 비교에서 뺀다.
- "우리 규칙이 낫다" = 같은 맥락·같은 stream 쌍에서, 같은 배정기 비교군 (S26 FIFO_FREE · EDF_FREE · A24 EDF · FIFO 자유) 둘 다보다 평균 AP 차이가 오차 밖 (S26 > 0.18 ℃ · A24 > 0.354 ℃) 이고, 쌍의 ≥ 80 % 가 같은 부호일 때. 개발과 확인 둘 다에서 그래야 한다.
- J 는 방향만 본다 (S26 은 실측 대비 약 4배 과대). NPU 가 끼면 J 는 기술만 한다.
- 기한 충족 수 차이 (서비스) 는 따로 판정하고, 열·에너지 판정과 섞지 않는다.
- 궤적이 동일하면 "차이 0 (동일 일정)" 으로 적는다. 평균으로 상쇄된 동률과 구분한다.
