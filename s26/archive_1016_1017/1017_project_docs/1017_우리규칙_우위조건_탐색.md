## 2. S26 탐색 (개발 stream, 48 부하 × 맥락 3 × 표본 2~4)

- **RL 추가 시도**: ATC 선택을 특징으로 둔 잔차 선형 RL (REINFORCE) 을 개발 부하로 2회 학습 → 규칙보다 개발 점수가 같거나 낮음 (8230 → 7520 ~ 7710). **이 엔진에서 RL 은 규칙을 넘지 못함** (간단한 RL · 짧은 학습 한계).

## 5. "시뮬 값을 어떻게 바꿔야" 에 대한 답
- **바꿀 것 = 부하 조건**: 요청 몰림을 길게 (25 ~ 75 s) · 간격 좁게 (0.537 ~ 0.65 s) · 탐지 비중 높게 (묶음당 탐지 3) → 장치 용량 근처~초과. 이 영역이 우리 규칙의 서비스 우위가 나오는 곳.
- **바꾸면 안 되는 것 = 물리 계수·납기**: 모형은 SHA 로 봉인돼 있어 조민규가 바로 알아본다. 우리 정책에 맞춰 계수를 고치면 결과 조작이 되고, 실측 재현 오차 (R21) 도 다시 깨진다.
- **비교군은 강하게**: "빈 자원 채우기" 를 넣지 않으면 우리 이득을 과장하게 된다 (−206 J 가 0 이 된 사례).
