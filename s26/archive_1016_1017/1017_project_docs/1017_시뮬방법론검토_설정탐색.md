## 2. S26 — 골고루 쓰는 설정 탐색

우리 규칙 (롤링+ATC+경로 선택) 의 **효용식 한 줄만** 바꾼 변형 (물리 무접촉):
- w = 에너지 가중치 (0 = 열만, 1 = 에너지만, 기본 0.5)
- swT = 온도 전환형: 전달된 AP < T 면 에너지 우선 (GPU), 이상이면 열 우선 (NPU)

개발 48 (stream 260016200~207) → 확인 48 (260017300~307), 6맥락.

| 설정 | 분류 GPU/NPU | 가드 (개발·확인) | J (확인) | 평균 AP (확인) |
|---|---|---|---|---|
| 기본 w0.5 (= NPU 만) | 0 / 4608 | 48·48 | 194.1 | 32.37 |
| **sw32 (골고루: GPU 25 %)** | 1152 / 3456 | 48·48 | 194.9 | 32.40 |
| sw34 (GPU 52 %) | 2400 / 2208 | 48·48 | 194.8 | 32.42 |
| w1 (= GPU 만) | 4608 / 0 | 48·48 | 192.4 | 32.47 |
| 비교: FIFO 병행 GPU | — | 48·48 | 201.7 | 32.52 |
| 비교: FIFO 병행 NPU | — | 48·48 | 205.0 | 32.42 |

- 골고루 쓰면 에너지↓·열↑ 맞바꿈만 생긴다 (w 0~0.7 은 전부 NPU, 0.8~1 은 전부 GPU — 대리값 차이가 작아 중간이 거의 없음). 기본보다 더 좋은 설정은 없다 [시뮬].
- **우리 규칙이 비교군을 확실히 이기는 곳 = 몰림 (M128)**: 확인 표본 24/24 에서 FIFO 병행 GPU·NPU 둘 다보다 J·평균 AP 가 낮다.

| 몰림 M128 (확인 24쌍) | ΔJ | ΔAP 평균 | Δ최고 AP |
|---|---|---|---|
| 기본 − FIFO 병행 GPU | −19.1 J (24/24) | −0.19 ℃ (24/24) | −2.3 ℃ |
| 기본 − FIFO 병행 NPU | −21.9 J (24/24) | −0.10 ℃ (24/24) | −0.4 ℃ |
| sw32 − FIFO 병행 GPU | −17.6 J (24/24) | −0.17 ℃ (24/24) | −1.9 ℃ |
| sw32 − FIFO 병행 NPU | −20.4 J (24/24) | −0.07 ℃ (24/24) | 0.0 ℃ |

- 분산 (SMOOTH128) 에서는 우리 규칙 = FIFO 병행 NPU 와 거의 같은 일정 (차이 0). 몰림에서만 순서 (ATC) 가 일을 한다.
- 정직 경계: J 크기는 4배 과대 가능 + 순서 효과의 J 부호를 R21 이 1/3 만 맞힘 → "J 방향 24/24 (모형)" 까지. AP −0.10 ~ −0.19 ℃ 는 오차 0.18 ℃ 경계.

## 3. A24 — 설정 탐색

- RL 체크포인트 EP16 · EP32 · EP64, 서비스 목표 α 0.95 · 1.0 을 RL 이 놓치던 3조건 (분류 25 % · 몰림) 에 시험 → **어느 것도 48/48 못 함** (39 ~ 47/48). 조민규 DEV 점수에서도 세 체크포인트 모두 서비스 부족 > 0 [시뮬 · 기록].
- 정책 간 열·에너지 차이는 0.01 ~ 0.14 ℃ · 1 ~ 2 J (기저 92 %) — 모형 구조상 (온도→속도 없음) 어떤 설정으로도 "열·에너지 우위" 가 오차 밖으로 나오기 어렵다.
- A24 에서 유의미하게 말할 수 있는 것 = **서비스**: 고정 직렬 (지금 방식) 718/1152 → 자유 배정 FIFO 1124 → 기한 인지 순서 (ATC 계열) 1152/1152 (확인 24조건 전부).
