## 반드시 지킬 문장 규칙
- "RL 이 열을 줄였다" 금지 — 열은 페이싱 결과. 페이싱 + 롤링+ATC+RL 결합 시스템은 시험 안 됨.
- RL 우위는 "기기가 열에 민감할수록" 조건 문장으로만. 실측 모형에서 RL 이 규칙보다 낮은 결과를 같은 쪽에 함께.
- 에너지 = 동등 · 절감 아님. E2 k=4 ΔJ +0.2 · ΔAP +0.001 · Δ최고 +0.02 = "모형 예측상 소폭 증가".
- 가상 기기는 "실측 기반 모형을 확장한 가상 기기 시뮬레이션" (조민규 제안 명칭).
