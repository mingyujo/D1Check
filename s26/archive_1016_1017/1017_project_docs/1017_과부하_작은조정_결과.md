## 왜 부하만 늘려서는 분배가 잘 안 보이나
- S26 모형에서 분류는 한 번에 하나 (GPU·NPU 동시 불가). GPU 는 추가 차선이 아니라 같은 차선의 대체 → NPU 가 "감당 못 함" = 분류 차선 자체가 꽉 참. GPU 로 돌려도 처리량은 GPU 가 NPU 보다 빠를 때만 는다.
- 실측 모형에서 GPU·NPU 속도가 거의 같고 (GPU 는 뜨거우면 10 ℃당 약 2 % 빨라짐, NPU 는 그대로), 그래서 아주 뜨거운 심한 과부하에서만 GPU 가 조금 이득.
- 용량 절벽이 가파르다: 실측, 분류7·탐지1 묶음 25 s 몰림에서 간격 0.47 s → 정시 94~99 %, 0.45 s → 44~55 % (6개 정책 범위).
- NPU 우선 비교군 3개 (FIFO+채우기 · FIFO/EDF+빈가속기) 는 이 부하에서 정시가 소수점까지 같다 — NPU 가 늘 먼저 비어 GPU 를 한 번도 안 쓴다.
