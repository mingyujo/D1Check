# S26 동일 자원 조건 비교 결과 · 2026-10-16

**CPU·GPU·NPU 선택 조건을 맞추자 FIFO·EDF·우리 롤링+ATC의 추가 열·에너지 차이는0이었다.** 현재48조건에서 세 정책은 물리 궤적까지 정확히 같았다. 현재 주정책은 RL 학습 전의 규칙이다.

| 정책 | 기한 내 처리율 | 전128건 납기 충족 조건 | 평균 API J0~180 | 평균 AP35~180 |
|---|---:|---:|---:|---:|
| FIFO 자동배정 | 100% | 48/48 | 200.352058J | 32.396312℃ |
| EDF 자동배정 | 100% | 48/48 | 200.352058J | 32.396312℃ |
| 우리 롤링+ATC 자동배정 | 100% | 48/48 | 200.352058J | 32.396312℃ |

우리 정책의 FIFO·EDF 대비 추가 감소는 모두 **0J·0%·0℃**다. 모든조건의 개별차이도0이므로 평균으로 상쇄된 동률이 아니다.

## 왜 같은가

세 정책 모두 분류는 CPU/GPU/NPU를 비교한 결과 NPU96건, 탐지는 CPU32건을 선택했다. 48조건×128=6144회 실제 dispatch 중 시작 가능한 요청이2개 이상인 시점은1551회였지만 FIFO와EDF의 첫 선택이 달라진 시점은0회였고, 우리 ATC의 선택도FIFO와0회 차이였다. 세 정책은 모든48조건에서 실제 요청순서·route·단계/응답 시각·센서·전력/온도 곡선이 일치했다. WAIT도 모두0초였다. 현재 입력에서는 다른 정책이 다른 행동을 만들지 않았다. 이를 모든 부하에서 정책이 같거나 시뮬레이터가 어떤 일정 차이도 표현하지 못한다는 결론으로 확대하지 않는다.

이전 FIFO 병행205.662736J 대비 우리200.352058J의2.58% 차이는 같은 자원 조건의 순수 정책 효과가 아니었다. 이번 같은 자원/명목 배정기/병행·WAIT 조건의 비교에서는 그 차이가 사라졌다.

## 비교와 근거

분류CPU/GPU/NPU·탐지CPU, CG_DC/CN_DC 최대2·비선점·AVAILABLE, 명목 납기 예측/열·에너지 배정기와WAIT 자격/상한을 공유했다. FIFO/EDF는 지금 시작 가능한 ready 요청 중 도착순/절대기한순이다. 물리계수·고정0.8/2초·128요청·초기이력·요청별 난수 표본·기존 우리 정책은 변경하지 않았다.

FIFO/EDF 각48개와 수치 점검8개를 새등록에서 실행했다. 우리 정책48개는 이미 검산된 exact raw를SHA 검증해 재사용했다. 순수24검사·수치4쌍과104개 새환경/48개 재사용 결과의1405515검사·독립 비용재적분152건이PASS했다(최대수치오차1.13e-11). 새RL/NN/fit0이다.

API 추정J는 외부전력계 교정J가 아니고AP는 표면온도가 아니다. 기존 실측 재현오차와 모형전이 가정은 유지된다. 독립 실기기 절감 인증이 아니라 현재 모형·부하의 조건부 개발 비교다.
