## 식과 모형 가정

6개 상태의 자유 계수는 기존 공선 문제 때문에 쓰지 않는다. 입력은 현재 CPU/GPU/NPU 점유 `u_r ∈ {0,1}`이며, CPU 분류와 탐지의 비용 계수를 공유하고 병행 증분을 더한다. 이는 **측정으로 증명한 작업별 전력 동등성/병행 가산성이 아니라 차원을 줄이는 가정**이다. NPU 단독 등 노출이 부족한 상태는 외삽 표시를 유지한다.

전력 기억 상태: `dz_r/dt = (u_r-z_r)/τ_P`, `P = P_pre + Σ a_r z_r`, `E=∫Pdt` (W, J). τ=0은 즉시 점유 모델이다. 초기 z=0은 baseline 이후 잔류 전력이 없다는 가정이며 실제 baseline 이상치는 제거하지 않는다. 부하 종료 뒤 z가 감쇠하여 tail을 표현한다.

열: `dy_{r,f}/dt = β(u_r-y_{r,f})`, `dy_{r,s}/dt = β/10(u_r-y_{r,s})`,
`T = R + (T0-R)exp(-βt) + Σ g_r[m y_{r,f}+(1-m)y_{r,s}]` (℃).
1pole m=1, 2pole m=0.6/느린 시정수10배는 **고정 구조 가정**이다. AP와 SKIN은 별도로 적합한다. BAT/PA, 온도→서비스 감속, CPU DVFS, 전류계 절대 교정은 만들지 않는다. 에너지와 열을 각각 센서에 맞추며 두 출력의 열역학적 결합이 검증됐다고 주장하지 않는다.

비음수·상한 회귀: 전력 a∈[0,20]W, 열 g∈[0,60]℃. 상한은 안전장치/설계 가정이지 실측 상한이 아니다. 목적 `mean((Xc-y)^2)+λ mean((c-c_shared)^2)`에서 shared prior는 **적합8세션만**의 전체 점유 회귀 값이다. 정규화는 W 또는 ℃에서 이루어지며 두 목적을 더하지 않는다. 행/세션 균등 가중, 상한 활성화·행렬 rank/condition/VIF·단독/병행 노출을 보고한다. 계수 출력은 식별 PASS를 뜻하지 않는다.

## 유한 후보·선정·불확실성

1. 전력 τP `[0,5,15]`초 × λ `[0,0.1,1]`: 9적합. 개발 세션120초 J 절대 상대오차 평균, 동률이면5초 전력창 RMSE, 후보 순번으로 선정.
2. AP/SKIN 각각 β `[0.01,0.03,0.06,0.12,0.25]`/s × m `[1,0.6]` × λ `[0,0.1,1]`: 30적합씩. 개발 세션 평균 `MAE+0.25×|peak误差|`로 선정, 동률 후보 순번. 0.5초 입력 격자와 실제 센서 시각의 선형 보간을 사용한다.
3. 선정 설정은 적합8에서 그대로 동결한다. 개발을 포함한 재적합/확인 뒤 튜닝을 하지 않는다. 적합의4개 `(block,pair)` 그룹을 재표집하는 paired bootstrap100회, seed61201. 고정 선정 설정의 전력/AP/SKIN 각100적합. **총369회**, cap400, PC 활성1200초/저장 여유120초. 소스·입력·등록 SHA와 계산 횟수를 원장에 남긴다.
4. 선정 모형/100 bootstrap/나머지 고정 후보가 만드는 예측 범위를 함께 보고한다. bootstrap 2.5~97.5백분위는 **작은 기존 자료의 조건부 민감도 범위**, 모집단95% 보장구간이 아니다. 모든 후보의 min/max는 후보 구조 민감도다. 센서 잔차·단위 오차·미식별된 임의 계수·미관측 상태를 모두 포괄하지 못한다. 범위가 겹치거나 순위가 바뀌면 비용 우위를 확정하지 않는다.
5. 실측 일정 조건 A의 J120/AP/SKIN 경로 MAE·최고 오차를 모든 세션별로 공개한다. 공통120초 + 실제 냉각 중 최대60초의 열 경로를 사용하며, R4S에서도 시작180초만 본다. 기존 a24fmt와 동일120초 J/최대180초 AP 회고 수치를 병기한다. 선택에 사용하지 않는다.
6. 저장된 최종512 + NPU-off256 = **768 일정만 비용 후처리**한다. 신규 서비스 에피소드0, PPO 업데이트0. 공통 Ppre/R/T0는 적합 자료 중앙값을 가정하며 모든 정책에 동일하게 준다. 비용 경로 계산은 결과 원장만 읽는 사후 분석으로 정책 입력에 주입하지 않는다. 새 도착이나 미래 실제 처리시간을 dispatch 선택에 쓰지 않는다. 새 비용을 학습한 PPO라고 부르지 않는다.
