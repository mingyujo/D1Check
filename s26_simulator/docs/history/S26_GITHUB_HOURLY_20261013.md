# S26 GitHub 매시간 확인·시뮬레이터 개선

2026-10-13 KST. 사용자 지시로 현재 채팅의 매시간 후속 자동화 `s26-github`를 ACTIVE로 생성했다. 대상은 mingyujo/D1Check의 모든 s26-* 브랜치다. 새 브랜치도 확인하며 관측한 커밋과 실제 반영·검증 완료 커밋을 구분한다.

현재 새 s26-m6 04951981eeade024a0c4f5b15c7d33c537d6c115는 M6-A E4/K2/P개발6 측정 결과를 포함한다. 개요와 Git object 존재까지 확인했고 원자료 인계·계수 개발·검증은 아직 대기다. 이미 반영했다고 표시하지 않았다. state.json에 우선 처리 대상으로 기록했다.

목표는 스케줄링별 요청 순서·자원 배정·허용된 병행의 결과 차이가 크게 드러나는 시뮬레이터다. 새 실측 근거에 맞춘 프로파일과 큰 차이를 보여주는 탐색 가정을 구분하고, 같은 환경 안에서 모든 정책을 비교한다. 전체 평균과 결과를 보고 선정한 시연 예제는 분리한다.

새 자료가 없으면 추가 fit/시뮬레이션/학습을 하지 않는다. 새 자료가 있으면 내용·중복·단위·시간·완료량·품질/지원 범위를 확인하고 별도 버전에서 필요한 모델 보완과 작은 비교를 수행한다. 한 회차 최대50분·PC worker 최대2, 더 긴 작업은 원장/체크포인트로 이어가며 중복 실행을 피한다. 독립 전력계 부재는 측정 정확도의 범위로 기록한다.

기존 모델·원자료·가중치·ZIP·실패와 실행 이력은 보존한다. 다른 채팅의 D1-SCHED-DEADLINE-MEAN-21 학습 및 d1check-atc-ppo 자동화는 변경하지 않는다. 진행 중인 실험이 쓰는 공통 파일을 수정하지 않고 새 경로/버전을 사용한다. APK/기기/GitHub push/PR/외부 메시지는 수행하지 않는다.

자료·상태가 바뀌지 않았으면 조용히 종료하고, 새 자료 반영/검증 완료·의미 있는 실패·사용자 판단이 필요한 사항만 알린다. 이 회차는 자동화 설정·읽기 확인만 수행했다. 신규 fit/학습/시뮬레이션/기기 실행0이며 기존 전체 실행 이력을0으로 바꾸지 않았다.
