## 확보한 근거

입력 ZIP SHA256은 `1916b004fde9f975fdd7ae64578f63cff9316f14da08ae6641d3a6bc33c88de5`이다. 대표19군3048요청과 추가CPU252요청, EDD 첫 시도 회수실패를 분리한다. 기록 검산은3300요청·일반readback416건을 통과했다.

M128 직렬의 전체 점유시간 합은12.780527초이며 병행CG는14.425730초다. 병행CG의 실제 겹침5.761325초를 빼면 점유 합집합은8.664405초다. 개별 작업 점유시간이 짧아져서 얻은 이득이 아니라, 실제 겹침으로 대기열 누적이 줄어든 관찰을 모형이 표현해야 한다. 이는 세션 내부 시간 회계이며 시작 조건이 다른 세션 간 인과계수 식별은 아니다.

기존 모형의 일반 응답은 저장 완료, M8은 실제readback 완료다. 기존 온라인WAIT는 사건 도착에 반응하고 실제12초 상한을 갖지만 M8 처방WAIT는 타이머 동안 도착을 쌓으며 명목량과 실제초과를 별도로 기록한다. 두 계약을 다른 버전으로 유지한다.
