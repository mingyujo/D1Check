# S26 상대부하를 A24와 맞춘 결과

S26 도착 간격만 조정해 current_neutral 공개 평균 기준의 명목 상대부하를 A24와 같은 .7/1.1로 맞췄다. 요청 수·작업량·중요도·상대 납기·환경 난수·처리시간 모형·전력/열 계수·PPO 가중치는 유지했다. 실제 열 상태에서의 자원 활동률까지 같게 만든 비교는 아니다.

원20 672개 결과를 SHA로 재사용했다. 바뀐 S26 30조건×7정책=210새환경이고, 변경 후672행은 새210+재사용462다. 아래 A24 결과는 새로 실행한 값이 아니라 변화 없는 기준이다.

**결과:** S26의6규칙 평균에너지격차는 53.87→17.64J(15.64→5.54%),평균AP격차는 0.961→0.321℃로줄었다. 두설정모두16/16조건전량완료다. 이번강한모형에서는상대부하를높이는방법이격차확대에효과가없었다.

## 자원 선택이 가까워진 관측 근거

일정 도착8조건에서Greedy의분류CPU배정은 188/320(58.750%)→38/320(11.875%)로줄었다. CPU가탐지에점유된동안가능한가속기경로를선택하면서정책간배정차이가줄어든것으로해석할수있다. 이는저장된배정결과와물리제약을기반으로한추론이며개별효과의기여율을분리한실측결론은아니다.

## 해석 범위

이번 차이는 같은 모형에서 도착 밀도를 바꾼 효과다. 새로운 휴대폰 실측 정확도 확인이나 PPO 재학습 결과가 아니다.

명목 부하가 같아도 S26의 처리시간, CPU/GPU/NPU 경로, 실제 실행·점유시간과 종료·냉각 시각이 A24와 같아지지는 않는다. 전력/열 계수는20의 탐색 가정이며 그대로 유지했다. 모든210새환경과전후672행·두도착난수·PPO상충·미완료를보존하고결과에맞춰프로필/가중치를다시조정하지않았다.

전체 paired_policy_deltas.csv/tier_spread.csv/policy_summary.csv/resource_usage.csv에 전후 변화와비용분해가있다. 신규학습/native/Adam/fit/기기/APK/외부전송0이다. 원20의674환경·원17~19의3,486환경 이력은수정하지않았다. 실제새소비는consumption과원장을따른다.

패키지 고정PPO2회도새도착원장·사건·J/AP·냉각결과를exact로재현했다. 이번실제신규소비는210+2=212환경/학습0이며입력검사외기존물리검사를불필요하게반복하지않았다.
