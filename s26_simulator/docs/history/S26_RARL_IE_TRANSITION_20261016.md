### 모형 경계와 필요한 최소 보완

현재 결과는 개발 실측 분포에서 생성한 새 합성 stream의 조건부 시뮬레이션 결과다. 실기기 독립 정확도나 실제 절감 인증은 아니다. GPU/NPU 독립 call 계수0은 식별 부재이며 전력0을 의미하지 않는다. 기저·공유·잔열은 그대로 포함했다. SERIAL 잠재벡터 공유·미측정 병행 간섭·이상적인 제어기 지연·열→실행시간 feedback 부재, CU96/DN32와 task/priority의 교란이 남는다. HAL AP와 표면온도도 구분한다.

IE의 명목 Eproxy/Q는 현재 선택 요청의 계획 대리값이다. rolling 계획마다 겹치는 값을 더해 세션 J/℃라 부르지 않는다. IE의 exact 공개 tuple과 PPO의 scaled/clipped float32 tensor는 공개 원자료가 같아도 표현·계산량이 같지 않다.

다음 보완은 기존 유효 증거의 충족 여부부터 확인하고, 누락된 모듈만 별도 등록으로 수행한다. 95세션을 다시 일괄 요청하거나 반복수를 임의 축소하지 않는다.

1. **계측과 경계:** 전류·전압·전하량의 단위/배율·방전 부호·값 변화와 읽기 주기·시각 원점·허용 gap·AP/에너지 창의 양측 표본·실제 readback/AVAILABLE를 검증한다. 임의1000배 보정·공백 보간·host pull의 응답 대체는 하지 않는다.

3. **열 이력과 입력 범위:** 같은 작업량의 CPU 준비/idle 준비 및 동일 초기 경계에서 온도·실행시간을 연속 기록해 열 이력과 timing 관계를 검사한다. task×priority를 교차하고 넓은 queue/도착 밀도 조건을 포함한다. SOC·초기 열·시간대·충전·거절·실패를 원장에 남기고 완료 요청만 고르지 않는다.
