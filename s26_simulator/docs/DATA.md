# 데이터·계보·포함/제외

## 현재 핵심 자료

현재 packet은 추론 81,736건/158세션의 시간 추정과 M8 whole-vector 8,636개를 연결한다. 비용 자료 원장은 기존131+M8/R21 97 등 총228세션 후보의 target별 계측 적격성을 따로 판단한다. 추론/단계/온도/전력은 분모가 서로 다르다. 결측·준비·재시도·실패를 완료 요청으로만 필터링하지 않는다.

R21은 7군×3블록=21대표/2,688요청이다. 원 첫 시도 앱거부1건은 별도 소비로 남고, index만 고친 동결 v2의 대표 재시도a2를 사용했다. API 단위 가설 적격 에너지는19/21이며 r범위 밖2건은 null이다. 이 측정은 신규 수치 예측 이전에 관찰되어 현재 보완/평가는 개발 역할이다. 새 독립 사전예측 검증이 아니다.

두 부하는 정확한 요청 manifest를 사용한다. M128은8건씩 몰림, SMOOTH128은 분산이며 현재 둘 모두 긴급 분류96/일반 탐지32다. 초기3블록은 저온/중온/고온 이름이 아니고 초기 기준AP 약30.9~31.1℃의 실제 이력이다. 표본8개는 Monte Carlo 변동이며 새 실기기8회가 아니다.

## 전체 아카이브

인계 스냅샷은 **60,878파일·25,905,850,340바이트**다. 내용 중복을 제거한 51,508개 blob을 gzip 압축하여 **13개 pack·3,356,701,479바이트**로 보관한다. 카탈로그는 별도 5,727,233바이트다. 제외 원장 56개 항목은 캐시/저장소 디렉터리 53개와 모바일 모델·설치 라이브러리 파일 3개다. 원자료 수와 캐시 디렉터리 수를 같은 분모로 세지 않는다.

| group | 파일 수 | 복원 바이트 |
|---|---:|---:|
| current | 10,702 | 9,606,248,649 |
| measurements | 6,049 | 1,099,126,096 |
| policy_history | 22,306 | 13,781,747,772 |
| history | 21,821 | 1,418,727,823 |

`data/ARCHIVES.json`에 카탈로그/pack마다 다운로드 URL·크기·SHA가 있다. 카탈로그는 파일별 원래 출처, 복원 경로, group, SHA와 gzip blob의 pack/offset을 기록한다. 같은 내용은 한 번만 저장하고 여러 원래 이름으로 복원한다. 원파일을 재가공한 단일 평균으로 대체하지 않는다.

| group | 내용 |
|---|---|
| `current` | S26-UNIFIED-DYNAMICS·S26-INTEGRATED-MODEL의 소스/동결/정규화 V3/V4/V5/모형/원시 예측/원장/감사/실패/중간본 |
| `measurements` | 과거 M5/M6/M7/M8 수신·정정·동결·R21 원ZIP, 실기기 원기록/수신 파생물과 참조 원묶음 |
| `policy_history` | 과거 RARL/IE/통합 정책의 학습 경험·RNG·체크포인트·원결과·선정/감사 |
| `history` | 이전 비용·동적·NPU·pair·예측기·모바일 비교군 연구와 한국어 보고·과거 HTML |

## 제외하는 항목

`.git`, 캐시/빌드 산출물/설치 런타임, 개인 서명키/자격증명, 모바일 `.tflite`/APK/상용 런타임 binary는 전송하지 않는다. 특히 EfficientDet-Lite0 exact binary의 재배포 귀속은 원 프로젝트에서 미확정이므로 원 URL·SHA 확인 후 각 실행자가 직접 확보해야 한다. 그 파일이 든 ZIP도 원 그대로 공개하지 않고 제외 원장에 남긴다. 사용자 요청의 시뮬레이터 학습 체크포인트 `.pt`와 측정 배열 `.npz`는 여기에 해당하지 않아 포함한다.

실제 제외 경로·이유는 `data/ARCHIVES.json`의 `excluded`다. 필요한 원 측정 데이터와 실행 가능한 공통 모형/정책 source·학습 기록을 포함하는 것과 모바일 앱·모델 binary 배포는 구분한다. 원문 계약/라이선스/모델SHA는 데이터·기존 문서에 보존했다.

현재 핵심 Node 실행/화면은 외부 모델 binary나 Python 설치 없이 확인할 수 있다. 과거 Python 연구 코드를 다시 실행하려면 해당 아카이브의 등록·의존성을 확인한다. NumPy/PyTorch/SciPy 및 Android 의존성은 연구별로 다르며, 설치 런타임을 연구 source 라이선스로 일괄 재허가하지 않는다. 이 인계 폴더는 기존 자료의 저작권·모델 재배포 조건을 변경하지 않는다.

## 데이터 의미 경계

API 전류·전압 단위 가설의 J와 외부 전력계 교정J를 구분한다. AP 온도와 표면온도는 다르다. 실측 활동을 조건으로 맞춘 비용 오차와 새 일정이 생성한 활동 차이도 별개다. current phase-transfer 미채택 모형은 연구 후보이며 파일이 있다는 이유로 적용됐다고 부르지 않는다. 자세한 원인 분해는 current 아카이브 `SIMULATION_ANALYSIS_V1/ROOT_CAUSE_DECOMPOSITION.json`에 있다.
