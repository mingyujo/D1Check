5. 하나의 모형, 여러 조건의 예측

실측 자료 통합

기존·신규 자료를 하나의 공통 처리시간·AP·전력 모형에 연결했습니다. 블록은 별도 시뮬레이터가 아니라 시작 이력입니다.

변동은 유지

초기 상태와 처리시간 변동은 각각 예측하고 결과에서 합칩니다. 평균 입력 하나로 바꿔 병행·열의 비선형 효과를 잃지 않습니다.

성능과 손해 함께

열·에너지와 납기·전량완료를 함께 봅니다. 표본 8개는 새로운 실기기 8회 측정이 아닙니다.

검증 범위와 다음 보완

이 화면은 등록된 444회 중 동일 조건 비교 192회의 저장 결과를 요약합니다. R21을 이미 본 뒤 보완한 개발 검증이며 독립 실기기 확인이 아닙니다. 현재 초기 기준 AP는 약 30.9~31.1℃로, 넓은 고온 범위의 검증은 포함하지 않습니다.

처리시간의 온도·병행 연관을 진행 속도로 옮긴 전이 가정, 과거 처리 단계 잔차, API 전력 단위 가정이 포함됩니다. 일부 직렬군의 에너지 과대예측은 보완 대상입니다. 최신 처리 단계 보완 모형은 아직 이 저장 결과에 적용되지 않았습니다. 우리 정책의 최적화와 새 RL 학습은 환경 보완 이후입니다.
