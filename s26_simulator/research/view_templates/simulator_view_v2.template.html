우리 정책이 사용할 환경의 처리시간·열·전력 예측을 점검합니다. 기존 자료와 새 실측을 연결한 하나의 모형입니다. 목표는 전 요청의 기한을 지키면서 열·에너지 절감 폭을 키우는 것입니다.

검증 결과를 불러오는 중

API 전력 단위 가정의 에너지 추정입니다. AP 센서는 표면온도와 다릅니다. R21을 이미 본 뒤 보완한 개발 검증이며 새 독립 실기기 확인이 아닙니다. RL 학습은 이 단계 이후입니다.

표의 FIFO·EDF는 환경 검증용 기준입니다. 새 롤링+ATC+RL 학습 결과는 이 표에 포함되지 않았습니다. 다음 최적화의 우선순위는 우리 정책 자체의 납기·열·에너지 성능입니다.

모든 방법에 같은 128건·초기 이력·기한·CPU/GPU 병행 지원을 제공합니다. 직렬은 실측 계약 재현용, 병행 EDF와 병행 FIFO는 동등한 자원 조건의 비교군입니다.

4. 어떤 근거를 어디에 썼나?

실측에서 온 것

기존·신규 228세션 자료 원장, 경로별 추론·처리 단계, 실제 병행 지원, R21 요청표와 초기 센서 이력.

자료로 추정한 것

처리시간의 온도·겹침 연관, 공유 단계와 잔열을 포함한 AP, 양의 전력을 예측하는 Gamma 모형. 정책별 절감 상수는 없습니다.

전이 가정인 것

온도·겹침 연관을 진행 속도에 적용, 과거 단계 잔차의 새 일정 전이, 경로와 독립인 enqueue 지연, 센서 주기 2.3초·지연 0.2초.

검산·불확실성과 다음 보완

열·에너지 차이를 크게 만드는 것이 목표여도 실측보다 과장된 격차는 개선으로 채택하지 않습니다. 병행 효과와 순서 효과를 분리하고, 납기 위반·peak 악화·잔열·모형 오차를 함께 봅니다. 처리 단계의 조건부 전이가 부정확하면 그 경로를 별도 새 모형에서 보완합니다.
