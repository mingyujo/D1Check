## 고정 비교 설계

- FIFO_STATIC/EDF_STATIC/ATC_STATIC와 FIFO_STATE/EDF_STATE/ATC_STATE의6군. STATIC은 기존 명목 납기/비용 배정기, STATE는 현재 온도·공개 점유/관측 단계 이력으로 후보의 비용을 새로 예측하는 배정기다. 각 allocator 내에서 요청 순서 효과를 비교하고 STATIC↔STATE에서 배정 개선 효과를 분리한다. 동일 공개정보/후보/실제mask/명목위험필터를 제공한다.
- 순서: 실행가능 ready 중 FIFO, 절대기한 EDF, 기존 ATC 위험/우선순위. STATE에서도 동일 ATC 정의를 유지한다. 다단계 최적화/RL 성과로 표시하지 않는다.
